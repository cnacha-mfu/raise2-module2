## 🗄️ ข้อมูลถูกเก็บอย่างไร

| โฟลเดอร์ (collection) | ชื่อไฟล์ (document id) | เก็บอะไร | ใครอ่านได้ |
|---|---|---|---|
| `slots` | `2026-08-30_0930` | ช่องนี้ถูกจองแล้ว + uid ของคนจอง | ผู้เรียนทุกคน (เห็นแค่ว่าเต็ม ไม่เห็นชื่อ) |
| `appointments` | `2026-08-30_0930` | วัน เวลา ชื่อ อีเมล เรื่องที่อยากปรึกษา | **เจ้าของคิว** กับ **ผู้สอน** เท่านั้น |
| `quota` | `{uid}_w6` | กันจองเกินโควตาของสัปดาห์นั้น | เจ้าของกับผู้สอน |

**การจอง 1 ครั้ง = เขียน 3 ไฟล์พร้อมกันในชุดเดียว (batch)** สำเร็จทั้งหมดหรือไม่สำเร็จเลย

- **กันจองชนกันได้เองโดยไม่ต้องล็อกอะไรเพิ่ม** — ชื่อไฟล์คือรหัสช่อง ถ้ามีไฟล์นั้นอยู่แล้วการสร้างจะล้มเหลวทันที
  สองคนกดพร้อมกันวินาทีเดียวกัน จะมีคนเดียวที่ได้ อีกคนได้ข้อความว่าช่องถูกจองไปแล้ว
- **กันจองเกินโควตาด้วยหลักการเดียวกัน** — ชื่อไฟล์ `quota` คือ `{uid}_w{สัปดาห์}` สร้างซ้ำไม่ได้

## 🆘 ติดแล้วทำอย่างไร

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| กดเข้าสู่ระบบแล้วขึ้น `operation-not-allowed` | ยังไม่ได้เปิด Google ในหน้า Authentication → ทำตามหัวข้อ **ต้องทำก่อนใช้งานครั้งแรก** ด้านบน |
| เข้าได้แต่ขึ้นว่า "บัญชีนี้ยังจองไม่ได้" | อีเมลไม่ได้อยู่ในโดเมนที่อนุญาต → แก้ `ALLOWED_DOMAINS` ใน `config.js` **และ** `domainOk()` ใน `firestore.rules` |
| หน้าผู้สอนขึ้นว่า "บัญชีนี้ไม่ใช่ผู้สอน" | อีเมลไม่ตรงกับ `ADMIN_EMAILS` → แก้ทั้ง `config.js` และ `isAdmin()` ใน `firestore.rules` |
| จองแล้วขึ้นว่าระบบไม่อนุญาต | ช่องถูกคนอื่นจองไปพอดี หรือจองครบโควตาสัปดาห์นั้นแล้ว |
| เบราว์เซอร์บล็อกหน้าต่างล็อกอิน | อนุญาต pop-up ของเว็บนี้ แล้วลองใหม่ |
