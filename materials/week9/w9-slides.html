🧪 ช่วงที่ 1 — ให้ AI ทดสอบระบบแทนเรา · 1 ชม. 20 นาที

🗒️ เริ่มด้วยคำถามให้ห้องคิด — "หลังแก้โค้ดครั้งล่าสุด ใครไล่กดครบทุกหน้าบ้างครับ" · มักไม่มีใครยกมือ แล้วพูดว่า "นั่นแหละคือปัญหาที่ช่วงนี้แก้"

ทำไมต้องทดสอบอัตโนมัติ

  • ทุกครั้งที่แก้อะไร ควรไล่กดใหม่ทั้งระบบ
  • ระบบมีหลายหน้า หลายเส้นทาง — กดเองทุกรอบไม่ไหว
  • บั๊กที่หลุดถึงผู้ใช้ แพงกว่าบั๊กที่เจอในเครื่องเรา
  • ให้หุ่นยนต์กดแทน แล้วเราไปทำอย่างอื่น
🗒️ พูดว่า "เราไม่ได้ทดสอบเพราะอยากได้ใบรับรอง เราทดสอบเพราะไม่มีเวลากดเองทุกรอบ" · บอกว่าชุดทดสอบนี้เป็น 1 ใน 5 ของส่งมอบให้ Module 3

อ่านโค้ดอย่างเดียวไม่พอ

  • ที่ผ่านมาเราตรวจงานด้วยการอ่านโค้ดกับกดเองทีละหน้า
  • อ่านแล้วดูดี ไม่ได้แปลว่ากดแล้วไม่พัง
  • และกดเองทุกรอบที่แก้โค้ด เราไม่มีเวลา
  • สัปดาห์นี้เราตั้งผู้ช่วยอีกตัว — 🧪 Tester
🗒️ พูดว่า "ทุกสัปดาห์ที่ผ่านมา คนตรวจว่าระบบยังใช้ได้คือเราเอง และเราตรวจได้เท่าที่เรามีเวลา" · โยงเข้าวันนี้ — "วันนี้เราจะให้ AI อีกตัวเปิดเบราว์เซอร์กดใช้ระบบเราแทน"

Sub-Agent แปลว่าอะไร — ทวน 1 นาที

  • Sub-agent = ผู้ช่วย AI อีกตัวที่มีหน้าที่เฉพาะ
  • เราตั้งชื่อ ตั้งหน้าที่ และตั้งขอบเขตให้มัน
  • ตั้งค่าด้วยไฟล์ที่วางไว้ในโฟลเดอร์โครงงาน
  • เราไม่พิมพ์ไฟล์นี้เอง — สั่ง Claude สร้างให้
🗒️ พูดว่า "ไม่ใช่ AI ตัวใหม่ที่ต้องไปสมัคร มันคือ Claude Code ตัวเดิมที่เราสั่งให้สวมหมวกคนละใบ" · อ้างกลับสัปดาห์ที่ 8 ว่าเราทำแบบนี้มาแล้วครั้งหนึ่งตอนตั้ง Reviewer

ทำไมการมี context แยกกันถึงได้ผล

  • Context = "ความจำ" ของ AI ในหนึ่งบทสนทนา
  • ตัวที่เขียนโค้ด มีเหตุผลของตัวเองค้างอยู่ในความจำ
  • sub-agent เริ่มด้วยความจำเปล่า
  • จึงเจอสิ่งที่ตัวเขียนมองข้าม
🗒️ พูดว่า "นี่คือเหตุผลที่มันได้ผลจริง ไม่ใช่การตั้งชื่อใหม่ให้ดูดี" · เชื่อมกลับสัปดาห์ที่ 6 เรื่อง context บวมและ /clear

MCP คืออะไร

  • MCP = ช่องทางให้ AI ใช้เครื่องมือภายนอกได้
  • ปกติ AI พิมพ์ข้อความและแก้ไฟล์ได้เท่านั้น
  • มี MCP แล้ว AI หยิบเครื่องมืออื่นมาใช้ได้
  • เปรียบเทียบ: เหมือนต่อมือให้ AI
🗒️ พูดว่า "เหมือนเมื่อก่อน AI พูดได้อย่างเดียว ตอนนี้มันหยิบของได้แล้ว" · ไม่ต้องลงรายละเอียดว่ามันทำงานเบื้องหลังอย่างไร ห้องนี้ไม่ต้องรู้

Playwright คืออะไร

  • Playwright = หุ่นยนต์ที่กดใช้เว็บแทนคน
  • เปิดเบราว์เซอร์จริง · พิมพ์จริง · กดปุ่มจริง
  • แล้วบอกกลับมาว่าเห็นอะไรบนหน้าจอ
  • Playwright MCP = ต่อหุ่นยนต์ตัวนี้เข้ากับ Claude Code
🗒️ พูดว่า "เดี๋ยวจะได้เห็นเบราว์เซอร์เปิดขึ้นมาเองแล้วกดปุ่มเองสด ๆ ตรงนี้แหละที่ห้องมักจะฮือฮา" · บอกว่าเราสั่งเป็นภาษาไทย ไม่ต้องเขียนโค้ดเทสต์เอง

→

→
พังจริง = โค้ดผิด
→
