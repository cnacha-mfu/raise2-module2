# Node.js คืออะไร

- **Node.js** แปลว่า โปรแกรมที่ทำให้เว็บของเรารันบนเครื่องได้
- ติดตั้งไว้แล้วตั้งแต่ Module 1
- เราไม่ต้องเปิดมันเอง มันทำงานอยู่ข้างหลัง
- ไม่มี Node = พิมพ์คำสั่งแล้วขึ้นว่าไม่รู้จักคำสั่ง

> note: เปรียบเทียบว่า "เหมือนเครื่องเล่นแผ่น ถ้าไม่มีเครื่องเล่น แผ่นก็ยังเป็นแผ่น เปิดดูไม่ได้ Node คือเครื่องเล่นของโปรเจกต์เว็บเรา" แล้วบอกว่ากลุ่มไหนติดตั้งไม่ผ่าน ให้พิมพ์ 🔴 ในแชทตอนบ่าย อย่านั่งงมกันทั้งกลุ่ม

# npm และแพ็กเกจคืออะไร

- **แพ็กเกจ (package)** = ชิ้นส่วนสำเร็จรูปที่คนอื่นเขียนไว้
- **npm** = ร้านที่เราสั่งชิ้นส่วนพวกนั้นมาใช้
- เราสั่งครั้งเดียว มันโหลดมาเก็บในโปรเจกต์
- 📌 คุณไม่ต้องรู้จักชื่อแพ็กเกจ Claude จะเลือกให้

> note: พูดว่า "เหมือนทำอาหารแล้วซื้อน้ำพริกแกงสำเร็จ ไม่ต้องตำเอง npm คือร้านขายน้ำพริกแกงของโปรแกรมเมอร์" แล้วย้ำข้อสุดท้ายว่าไม่ต้องจำชื่อแพ็กเกจใด ๆ เลย

# terminal คือหน้าต่างพิมพ์คำสั่ง

- หน้าต่างสีเข้ม พิมพ์ข้อความแล้วกด Enter
- ไม่มีปุ่มให้กด มีแต่ตัวหนังสือ
- คำสั่งพิมพ์ผิด 1 ตัวอักษร = ใช้ไม่ได้ ถือเป็นเรื่องปกติ
- 📌 ใบงานมีคำสั่งให้คัดลอกทุกคำสั่ง

> note: พูดว่า "คนที่เพิ่งเคยเปิด terminal ตอน Module 1 ตรงนี้จะรู้สึกเกร็ง ผมบอกไว้ก่อนว่าพิมพ์ผิดไม่ทำให้เครื่องพัง คำสั่งผิดมันจะขึ้นข้อความบ่นแล้วจบ พิมพ์ใหม่ได้เลย"

# commit — ปุ่มเซฟที่ย้อนกลับได้

- **commit** = การกดเซฟหนึ่งครั้ง พร้อมเขียนกำกับว่าทำอะไรไป
- แต่ละ commit เป็นจุดที่ย้อนกลับมาได้
- **history** = รายการ commit ทั้งหมดเรียงตามเวลา
- ต่างจาก Ctrl+S ที่ทับของเก่าไปเลย

> note: พูดว่า "ทุกครั้งที่ commit คุณกำลังปักหมุดว่า ณ จุดนี้ระบบยังดีอยู่ ตอนบ่ายผมขอให้ทุกกลุ่มปักหมุดอย่างน้อย 6 หมุด และขอให้หมุดมีชื่อของสมาชิกครบทุกคน" แล้วบอกว่านี่คือ Checkpoint สุดท้ายของใบงาน

# Git คือปุ่มย้อนเวลา — ย้อนไปยืนตรงไหนก็ได้

```flow chain
commit ที่ 1 | commit ที่ 2 | *จุดที่ยังดี | พังหลังจากนี้
```

> note: ชี้กล่องซ้ายสุดก่อน แล้วไล่นิ้วไปทางขวาทีละกล่องพร้อมพูดว่า "ทุกกล่องคือหนึ่งครั้งที่เรากดเซฟ" · จบที่กล่องขวาสุดแล้วพูดว่า "ตรงนี้คือตอนที่ระบบพัง" · แล้วย้อนนิ้วกลับมาค้างที่กล่องเข้ม พูดว่า "Git พาเรากลับมายืนตรงกล่องนี้ได้ในไม่กี่วินาที ของที่พังหลังจากนี้ทิ้งไปได้เลย นี่คือเหตุผลทั้งหมดที่เราต้อง commit"

# ทำไม commit ทำให้กล้าปล่อยให้ AI แก้

- AI แก้โค้ดเร็วมาก และบางครั้งแก้พัง
- ถ้าไม่มี commit = พังแล้วกลับไม่ได้
- ถ้ามี commit = ย้อนกลับ 5 วินาที แล้วสั่งใหม่
- 🎯 commit คือสิ่งที่ทำให้กลุ่มคุณกล้าทดลอง

> note: นี่คือ "ทำไม" ที่ต้องพูดก่อนสอนวิธีทำ พูดว่า "กลุ่มที่ไม่ commit จะเริ่มกลัวการสั่ง AI แล้วจะทำงานช้าลงเรื่อย ๆ ผมเคยเจอด้วยตัวเอง เสียงานไปทั้งคืน"

# ถ้า AI แก้แล้วพัง — กด Esc สองครั้ง

```code
Esc         หยุด Claude กลางคัน
Esc Esc     เปิดเมนูย้อนกลับ เลือกจุดที่จะย้อน
/rewind     คำสั่งที่ทำงานเหมือนกด Esc สองครั้ง
```

- ย้อนได้ทั้งโค้ดที่แก้ไป และบทสนทนาที่คุยไป

# ทวนจาก Module 1 — Context Window คืออะไร

- **Context** = ความจำของ AI ในหนึ่งบทสนทนา
- **Context Window** = ขนาดความจำนั้น มีขีดจำกัด
- เต็มแล้วของเก่าจะเลือนไป ไม่ใช่หายทันที

# Token คืออะไร

- **Token** = หน่วยนับความยาวข้อความ
- ประมาณ 1 คำไทยสั้น ๆ = 1–2 token
- ไฟล์โค้ด 1 ไฟล์ = หลายพัน token
- ยิ่งใส่เยอะ ยิ่งกินความจำและยิ่งช้า

> note: พูดว่า "ไม่ต้องคำนวณเองนะครับ รู้ไว้ว่ามันคือหน่วยวัดว่าเรากินความจำไปเท่าไร" แล้วยกตัวอย่างว่าไฟล์หน้าจอ 1 หน้าของ FixIt กินประมาณเท่าไร โดยเปิดของจริงให้ดูถ้ามีเวลา

# เก็บสรุปแล้ว เริ่มรอบใหม่อย่างไร — /clear

```code
/clear      ล้างบทสนทนาปัจจุบันทั้งหมด แล้วเริ่มจากศูนย์
```

- 📌 ไฟล์ในโปรเจกต์ไม่ได้ถูกล้างไปด้วย ยังอยู่ครบทุกไฟล์
- สิ่งที่หายคือความจำของบทสนทนาเท่านั้น
- เริ่มรอบใหม่แล้ว วางสรุปสถานะเป็นข้อความแรก

> note: พูดว่า "เมื่อกี้ผมบอกให้เริ่มบทสนทนาใหม่ แต่ยังไม่ได้บอกว่าทำยังไง พิมพ์คำสั่งนี้ครับ /clear แล้วกด Enter บทสนทนาจะว่างเปล่าเหมือนเพิ่งเปิดโปรแกรม"
> note: **ย้ำข้อแรกให้หนักที่สุด** "คำว่าล้าง ทำให้คนกลัวจนไม่กล้าพิมพ์ ผมยืนยันว่าไฟล์ในโฟลเดอร์ของคุณไม่ได้หายไปไหนเลยสักไฟล์ สิ่งที่หายคือความจำของบทสนทนาอย่างเดียว" · ให้ทุกคนพิมพ์ในแชทว่าเข้าใจข้อนี้แล้วก่อนไปสไลด์ถัดไป

# ยังไม่อยากเริ่มใหม่ — /compact

```code

/compact เน้นเรื่องหน้าจอ    บอกได้ว่าให้เก็บเรื่องไหนไว้
```

- คุยต่อได้เลย ไม่ได้เริ่มใหม่ ของที่ตกลงกันไว้ยังอยู่
- เป็นทางเลือกกลาง ระหว่างคุยต่อจนมั่ว กับล้างทิ้งทั้งหมด

> note: พูดว่า "บางทีเราไม่อยากทิ้งบทสนทนาทั้งอัน เพราะคุยกันมาตั้งเยอะ คำสั่งนี้จะย่อบทสนทนาที่ผ่านมาให้สั้นลง คืนพื้นที่ความจำมาให้ แต่เราคุยต่อได้เลยไม่ต้องเริ่มใหม่"
> note: ชี้บรรทัดที่สองในบล็อกคำสั่งแล้วบอกว่า "เติมข้อความต่อท้ายได้ด้วยครับ เป็นการบอกว่าตอนย่อ ขอให้เก็บเรื่องไหนไว้เป็นพิเศษ" · สาธิตของจริงถ้าเวลาพอ

# Token = เวลา และเงิน

- ยิ่งใส่ข้อความเยอะ ยิ่งรอนาน
- ยิ่งใส่เยอะ ยิ่งใช้โควตาเปลือง
- บทสนทนายาว ๆ กินโควตาเร็วกว่าที่คิด
- 🎯 คุยให้ตรงประเด็นคือการประหยัดจริง

> note: พูดว่า "โควตาของทุกคนไม่ได้ไม่จำกัดนะครับ กลุ่มที่คุยยาวโดยไม่เริ่มรอบใหม่ จะหมดโควตากลางคาบแล้วทำงานต่อไม่ได้ ผมเห็นมาทุกรุ่น"

# ใช้ไปเท่าไรแล้ว — /usage

```code
/usage      เปิดดูปริมาณการใช้งานของบัญชีคุณ
```

- ⚠️ สิ่งที่เห็นขึ้นกับประเภทบัญชี ไม่เหมือนกันทุกคน
- บางแบบเห็นการใช้งานรายเดือน บางแบบเห็นเครดิตคงเหลือ
- 📌 เปิดดูเองว่าของคุณแสดงอะไร แล้วจดไว้
- ⚠️ คำสั่งเปลี่ยนตามเวอร์ชันได้ ไม่ได้ผลให้พิมพ์ `/help` ดู

> note: พูดว่า "เมื่อกี้ผมบอกว่าโควตาไม่ได้ไม่จำกัด คำสั่งนี้คือวิธีเปิดดูว่าตัวเองใช้ไปเท่าไรแล้ว พิมพ์ /usage แล้วกด Enter"
> note: **ย้ำข้อแรกให้ชัด** "ผมจะไม่บอกว่าคุณจะเห็นอะไรนะครับ เพราะแต่ละคนใช้บัญชีคนละแบบ บางคนจะเห็นเป็นตัวเลขการใช้งานรายเดือน บางคนจะเห็นเป็นเครดิตคงเหลือ ให้เปิดดูเองแล้วจดไว้ว่าของคุณแสดงอะไร"
> note: ปิดท้ายด้วยบรรทัดสุดท้าย "คำสั่งของ Claude Code เปลี่ยนได้ตามเวอร์ชัน ถ้าพิมพ์แล้วไม่ได้ผล ให้พิมพ์ /help ดูรายการที่ใช้ได้จริงในเครื่องคุณ" · อย่าเสียเวลาไล่แก้ให้ใครกลางคาบ

# เลือกรุ่นโมเดลให้เหมาะกับงาน

- งานเปลี่ยนสี ปรับข้อความ → รุ่นเร็ว
- งานวางโครงสร้าง ไล่หาสาเหตุที่พัง → รุ่นคิดหนัก
- ใช้รุ่นคิดหนักกับงานเล็ก = รอนานโดยไม่ได้อะไรเพิ่ม
- 📌 สลับรุ่นได้ตลอดในระหว่างทำงาน

> note: สาธิตสด ๆ ว่าสลับรุ่นตรงไหนในหน้าจอ Claude Code แล้วพูดว่า "ผมสลับวันละหลายสิบครั้ง งานเล็กใช้รุ่นเร็ว ได้คำตอบใน 5 วินาที"
