## 🎯 ส่งอะไร

📤 **ส่ง URL ของ repo อย่างเดียว** — `https://github.com/<ชื่อบัญชีของคุณ>/<ชื่อโครงงานของคุณ>`
ผู้สอนเปิด GitHub ตรวจเอง ไม่ต้องแนบไฟล์อะไรเพิ่ม · ใน repo นั้นต้องมีครบ 4 อย่าง

1. 🔗 **โค้ดระบบของคุณ** พร้อม commit **ในชื่อคุณ** อย่างน้อย 3 ครั้ง
2. 📸 โฟลเดอร์ `docs/` ที่มีภาพ **Firebase Console** เห็นข้อมูลตัวอย่างอย่างน้อย 5 รายการ
3. 📸 โฟลเดอร์ `docs/` ที่มีภาพ **หน้ารายการของระบบคุณ** ที่แสดงข้อมูลจาก Firestore จริง
4. 📝 โฟลเดอร์ `docs/` ที่มี **รูปถ่ายกระดาษโครงสร้างข้อมูล** ของคุณ

> 💡 **ไม่ต้องพิมพ์คำสั่งเอง** — วางไฟล์ภาพไว้ในโฟลเดอร์โครงงาน แล้วสั่ง Claude ว่า
> *"ช่วยย้ายภาพพวกนี้เข้าโฟลเดอร์ docs แล้ว commit ส่งขึ้น GitHub ให้ผม"*

## 📋 ทำตามนี้

### A — Fork repo เปล่า แล้วเอา prototype ของคุณใส่เข้าไป *(เหมือนใบงานส่วน A)*

1. เข้า `https://github.com/cnacha-mfu/raise2-starter` → กด **Fork** → **Create fork**
2. ในหน้า repo ที่ได้ → **Settings** → ช่อง **Repository name** → เปลี่ยนเป็นชื่อโครงงานของคุณ → **Rename**
3. สั่ง Claude โหลดลงเครื่อง แล้วคัดลอก prototype จาก Module 1 เข้าไป

```prompt
ช่วยโหลด repo ของผมจาก https://github.com/<ชื่อบัญชีของคุณ>/<ชื่อโครงงานของคุณ>
ลงมาไว้ในเครื่อง แล้วบอกวิธีเปิดดูในเบราว์เซอร์ให้ผมทีละขั้น
```

4. เปิดในเบราว์เซอร์ให้ได้ก่อน แล้วสั่ง *"ช่วย commit แล้วส่งขึ้น GitHub ให้ผม"* → ตรวจว่าประวัติขึ้น **ชื่อคุณ**

> 🔑 **ถ้าเครื่องนี้ยังไม่เคยล็อกอิน GitHub** ตอนส่งขึ้นครั้งแรกจะมีหน้าต่างของ GitHub เด้งขึ้นมา → **Sign in with your browser** → **Authorize** (เหมือนใบงานขั้น A2) · ไม่เด้งให้ใช้ทางสำรอง *"ช่วยติดตั้ง GitHub CLI แล้วพาผมล็อกอินด้วยวิธีเปิดเบราว์เซอร์"*
> 🚨 **ห้ามพิมพ์รหัสผ่านหรือโทเคน GitHub ลงในแชทของ Claude หรือเก็บลงไฟล์ในโปรเจกต์** — ล็อกอินในหน้าต่างเบราว์เซอร์เท่านั้น

> 📌 **repo นี้คือที่เดียวที่คุณจะใช้ส่งงานทั้ง 4 สัปดาห์** — สัปดาห์ต่อ ๆ ไปทำต่อใน repo เดิม ไม่ต้องสร้างใหม่

### B — เขียนโครงสร้างข้อมูลของคุณลงกระดาษ *(เหมือนใบงานส่วน B)*

ใช้กติกา 4 ข้อเดิม: โฟลเดอร์/ไฟล์/ช่องข้อมูล · ไม่มี JOIN · จดชื่อซ้ำ · ของเฉพาะรายการนั้นเป็นโฟลเดอร์ย่อย
**วงกลมสีแดง** รอบช่องที่จดชื่อซ้ำ แล้วเขียนว่าทำไมต้องจดซ้ำ

### C — สร้าง Firestore ของคุณ แล้วใส่ข้อมูลตัวอย่าง *(เหมือนใบงานส่วน C)*

สร้างโปรเจกต์ Firebase ของตัวเอง → Firestore → **Test mode** → คัดลอก `firebaseConfig` มาต่อกับเว็บ

```prompt
ช่วยเขียนสคริปต์ใส่ข้อมูลตัวอย่างลง Firestore ให้ผม
- <ชื่อโฟลเดอร์หลักของคุณ> 5 ไฟล์ ช่อง <ชื่อช่องของคุณทั้งหมด>
- <ชื่อโฟลเดอร์ที่สองของคุณ> 3 ไฟล์ ช่อง <ชื่อช่อง>
เขียนแผนให้ผมดูก่อน แล้วรอผมสั่งค่อยลงมือ
```

> ⚠️ **ตรงนี้ prompt ต้องยาว** เพราะเป็นรายชื่อช่องข้อมูล สะกดผิดแล้วระบบจะพังแบบเงียบ ๆ
> 🚫 **ห้ามใช้ข้อมูลจริงของคนอื่น** — โหมดทดสอบยังเปิดให้ใครก็อ่านได้ ใช้ชื่อสมมติเท่านั้น

### D — หน้ารายการอ่านจากฐานจริง *(เหมือนใบงานส่วน D)*

```prompt
ผมอยากให้หน้ารายการ<ชื่อหน้าของคุณ> อ่านข้อมูลจากโฟลเดอร์ <ชื่อโฟลเดอร์ของคุณ> ใน Firestore
ขอดูแผนก่อน อย่าเพิ่งลงมือ
```

พิสูจน์ว่าใช้ได้จริง: แก้ข้อมูลใน Firebase Console → กลับมากด F5 → ข้อความบนหน้าเว็บต้องเปลี่ยนตาม
