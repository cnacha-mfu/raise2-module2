## 📋 ทำตามนี้

### A — เอา prototype ของคุณขึ้น GitHub *(เหมือนใบงานส่วน A)*

> 📌 **การบ้านใช้ prototype ของคุณเองจาก Module 1** ไม่มี repo ต้นแบบให้ fork เหมือนใบงาน

**ถ้า prototype ของคุณอยู่บน GitHub อยู่แล้วตั้งแต่ Module 1** → ข้ามไปข้อ 3 ได้เลย ใช้ repo เดิมต่อ

1. เข้า **github.com** → กดปุ่ม **New** (สร้าง repository ใหม่) → ตั้งชื่อเป็นชื่อโครงงานของคุณ → **Create repository**
2. **จะเห็น:** หน้า repo เปล่า ๆ พร้อม URL `https://github.com/<ชื่อบัญชีของคุณ>/<ชื่อโครงงาน>`
3. เปิด Claude Code ในโฟลเดอร์ prototype ของคุณ แล้วสั่ง

```prompt
ช่วยเอาโฟลเดอร์นี้ขึ้น GitHub ที่ https://github.com/<ชื่อบัญชีของคุณ>/<ชื่อโครงงาน>
เริ่มเก็บประวัติงาน ปักหมุดแรก แล้วส่งขึ้นไปให้ผม
เสร็จแล้วบอกวิธีเปิดดูในเบราว์เซอร์ทีละขั้น
```

4. **จะเห็น:** เปิดหน้า repo บนเว็บ กด Refresh แล้วเห็นไฟล์ครบ และ commit ขึ้น **ชื่อคุณ**

> 🔑 **ถ้าเครื่องนี้ยังไม่เคยล็อกอิน GitHub** ตอนส่งขึ้นครั้งแรกจะมีหน้าต่างของ GitHub เด้งขึ้นมา → **Sign in with your browser** → **Authorize** (เหมือนใบงานขั้น A2)
> ⏳ ระหว่างนั้นจอ Claude จะนิ่งเหมือนค้าง ปกติครับ · มองไม่เห็นหน้าต่างให้กด `Alt + Tab` · ไม่เด้งเลยให้ใช้ทางสำรอง *"ช่วยติดตั้ง GitHub CLI แล้วพาผมล็อกอินด้วยวิธีเปิดเบราว์เซอร์"*
> 🚨 **ห้ามพิมพ์รหัสผ่านหรือโทเคน GitHub ลงในแชทของ Claude หรือเก็บลงไฟล์ในโปรเจกต์** — ล็อกอินในหน้าต่างเบราว์เซอร์เท่านั้น

> 📌 **repo นี้คือที่เดียวที่คุณจะใช้ส่งงานทั้ง 4 สัปดาห์** — สัปดาห์ต่อ ๆ ไปทำต่อใน repo เดิม ไม่ต้องสร้างใหม่
> 🆘 **prototype จาก Module 1 หายหรือรันไม่ได้** → นัด Consult ด่วน หรือทำหน้าเปล่า 1 หน้าไปก่อน แล้วค่อยเติมทีหลัง ห้ามค้างทั้งสัปดาห์

### B — เขียนโครงสร้างข้อมูลของคุณลงกระดาษ *(เหมือนใบงานส่วน B)*

ใช้กติกา 4 ข้อเดิม: โฟลเดอร์/ไฟล์/ช่องข้อมูล · ไม่มี JOIN · จดชื่อซ้ำ · ของเฉพาะรายการนั้นเป็นโฟลเดอร์ย่อย
**วงกลมสีแดง** รอบช่องที่จดชื่อซ้ำ · กระดาษแผ่นนี้ไม่ต้องส่ง ใช้กันตัวเองสับสนตอนสั่ง AI

### C — สร้าง Firestore ของคุณ แล้วใส่ข้อมูลตัวอย่าง *(เหมือนใบงานส่วน C)*

สร้างโปรเจกต์ Firebase ของตัวเอง → Firestore → **Test mode** → คัดลอก `firebaseConfig` มาต่อกับเว็บ

```prompt
ช่วยเขียนสคริปต์ใส่ข้อมูลตัวอย่างลง Firestore ให้ผม
- <ชื่อโฟลเดอร์หลักของคุณ> 5 ไฟล์ ช่อง <ชื่อช่องของคุณทั้งหมด>
- <ชื่อโฟลเดอร์ที่สองของคุณ> 3 ไฟล์ ช่อง <ชื่อช่อง>
เขียนแผนให้ผมดูก่อน แล้วรอผมสั่งค่อยลงมือ
```

> ⚠️ **ตรงนี้ prompt ต้องยาว** เพราะเป็นรายชื่อช่องข้อมูล สะกดผิดแล้วระบบจะพังแบบเงียบ ๆ
> 🚫 **ห้ามใช้ข้อมูลจริงของคนอื่น** — โหมดทดสอบยังเปิดให้ใครก็อ่านได้ ใช้ชื่อสมมติเท่านั้น

### D — หน้ารายการอ่านจากฐานจริง *(เหมือนใบงานส่วน D)*

```prompt
ผมอยากให้หน้ารายการ<ชื่อหน้าของคุณ> อ่านข้อมูลจากโฟลเดอร์ <ชื่อโฟลเดอร์ของคุณ> ใน Firestore
ขอดูแผนก่อน อย่าเพิ่งลงมือ
```

พิสูจน์ว่าใช้ได้จริง: แก้ข้อมูลใน Firebase Console → กลับมากด F5 → ข้อความบนหน้าเว็บต้องเปลี่ยนตาม
