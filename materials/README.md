## 🛠️ วิธีแก้สไลด์

**แก้ที่ไฟล์ `.md` เสมอ ไม่ใช่ `.pptx`** เพราะ `.pptx` จะถูกสร้างทับใหม่ทุกครั้ง

```
pip install python-pptx                                  # ครั้งเดียว
python scripts/build_slides.py materials/week6/w6-slides.md
```

ตัวแปลงจะเตือนให้เองว่าสไลด์ไหนยังไม่มีบันทึกผู้บรรยาย

## 🛟 ชุดกู้สถานะใน `shared/recovery/`

**ทั้งหมดเป็นไฟล์ md ที่มีชุด prompt ให้คัดลอกไปสร้างระบบขึ้นมาใหม่ — ไม่ใช่โค้ดสำเร็จ**

| ไฟล์ | สร้างระบบถึงสถานะไหน | ใช้ก่อนเริ่ม | เวลา |
|---|---|---|---|
| `leaveeasy-week5-end.md` | หน้าจอครบ 5 หน้า · ข้อมูลปลอม | ใบงานที่ 2 | ~12 นาที |
| `leaveeasy-week6-end.md` | + Firestore + CRUD + ขึ้นออนไลน์ | ใบงานที่ 3 | ~15 นาที |
| `leaveeasy-week7-end.md` | + ล็อกอิน + Rules + ปุ่ม AI + ค้นหา | ใบงานที่ 4 | ~15 นาที |

**ทำไมเป็น prompt ไม่ใช่โค้ดสำเร็จ** — ผู้เรียนยังได้ฝึกสั่ง AI ซึ่งคือทักษะของหลักสูตรนี้ · ได้โค้ดของตัวเองที่ AI อธิบายให้ฟังได้ · และเอา prompt ไปดัดแปลงใช้กับโครงงานตัวเองได้ทันที
ยอมแลกเวลา 10–15 นาที เพื่อไม่ให้กลายเป็นการคัดลอกไฟล์ของคนอื่น

> ⚠️ **TA อย่ารีรอที่จะให้ใช้** — ใครติดที่ Checkpoint เดิมเกิน 45 นาที ให้เริ่มใหม่ทันที
> เป้าหมายของคาบคือได้ฝึกเนื้อหาของ*สัปดาห์นี้* ไม่ใช่ซ่อมของสัปดาห์ที่แล้ว
