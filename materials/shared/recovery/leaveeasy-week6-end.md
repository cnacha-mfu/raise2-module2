## ชุดที่ 1 — สร้างโปรเจกต์และหน้าแรก ⏱ ~3 นาที

```
ผมกำลังทำเว็บระบบขอลาออนไลน์ชื่อ LeaveEasy

ข้อกำหนดที่ห้ามเปลี่ยน
- ใช้ HTML, CSS, JavaScript ธรรมดาเท่านั้น ห้ามใช้ framework ใด ๆ
  (ห้าม React, Vue, Vite, TypeScript, bundler)
- ห้ามใช้ไลบรารีจากอินเทอร์เน็ต ยกเว้น Firebase ที่ผมจะให้ต่อทีหลัง
- แยกเป็นไฟล์ .html หนึ่งไฟล์ต่อหนึ่งหน้าจอ
- ข้อความบนหน้าจอทั้งหมดเป็นภาษาไทย
- คอมเมนต์ในโค้ดเป็นภาษาไทย

ช่วยทำให้ผมทีละขั้น
1. เริ่มต้นโปรเจกต์ Node และสร้างไฟล์ .gitignore ที่กัน node_modules
2. เริ่มเก็บประวัติงาน แล้วปักหมุดแรกด้วยข้อความว่า "เริ่มต้นโปรเจกต์ LeaveEasy"
3. สร้างไฟล์ index.html เป็นหน้าแรก มีเฉพาะหัวข้อ "LeaveEasy ระบบขอลาออนไลน์"

ทำทีละข้อ แล้วบอกผมว่าแต่ละข้อเสร็จหรือยัง
```

**จะเห็น:** ข้อความ `added ... packages` วิ่งขึ้นมา ใช้เวลา 1–2 นาที · **ปล่อยให้ทำจนหยุด อย่ากดอะไรขัด**

จากนั้นเปิดที่อยู่ที่ Claude บอกมาในเบราว์เซอร์

🚩 **ตรวจ:** เบราว์เซอร์ขึ้นหน้าเว็บที่มีหัวข้อ LeaveEasy

## ชุดที่ 2 — ข้อมูลปลอมสำหรับหน้าจอ ⏱ ~2 นาที

> 📌 ข้อมูลชุดนี้ใช้ให้หน้าจอมีอะไรให้แสดงก่อน · ในชุดที่ 5 จะใส่ข้อมูลชุดเดียวกันนี้ลง Firestore

```
ช่วยสร้างไฟล์ js/data.js เก็บข้อมูลปลอมทั้งหมดไว้ที่เดียว
ใช้ชื่อสมมติเท่านั้น ห้ามใช้ข้อมูลจริงของใคร

1. users 3 คน แต่ละคนมี id, name, email, role
   - u001 สมชาย ใจดี  role เป็น employee
   - u002 สมหญิง รักงาน role เป็น manager
   - u003 สมศรี ตั้งใจ role เป็น hr

2. leaveTypes 3 แบบ แต่ละแบบมี id, name
   - lt001 ลาพักร้อน / lt002 ลาป่วย / lt003 ลากิจ

3. leaveRequests 5 ใบ แต่ละใบต้องมี field ครบชุดนี้
   id, title, reason, status,
   requesterId, requesterName,
   approverId, approverName,
   leaveTypeId, leaveTypeName,
   startDate, endDate, createdAt
   ใช้ไอดี lr001 ถึง lr005
   สถานะใช้ได้ 3 ค่าเท่านั้นคือ รอพิจารณา, อนุมัติ, ไม่อนุมัติ
   ให้กระจายสถานะให้ครบทั้ง 3 ค่า อย่าให้เหมือนกันหมด

4. approvals ความเห็นการอนุมัติ แต่ละอันมี id, requestId, authorId, authorName, message, createdAt
   ใบที่สถานะ ไม่อนุมัติ ต้องมีความเห็นอย่างน้อย 1 อันเสมอ

สำคัญมาก ชื่อ field ทุกตัวต้องสะกดตรงตามที่ผมเขียนไว้ข้างบนเป๊ะ
เพราะเดี๋ยวผมจะใส่ข้อมูลชุดนี้ลง Firestore โดยไม่เปลี่ยนชื่อ
Firestore แยกตัวพิมพ์เล็กใหญ่ สะกดต่างกันคือคนละช่อง
```

🚩 **ตรวจ:** เปิดไฟล์ `js/data.js` แล้วเห็นใบลา 5 ใบ ที่มีทั้ง `requesterId` และ `requesterName` อยู่คู่กัน

## ชุดที่ 3 — หน้าจอทั้ง 5 หน้า ⏱ ~4 นาที

> ⚠️ **วางทีละหน้า อย่าวางทั้ง 5 หน้าในคำสั่งเดียว** — สั่งทีเดียวหลายอย่างคือสาเหตุที่โปรเจกต์พังบ่อยที่สุด
> ทำเสร็จหนึ่งหน้า ให้ commit หนึ่งครั้ง แล้วค่อยทำหน้าถัดไป

**หน้าที่ 1 — รายการใบลา**
```
ปรับ index.html ให้เป็นหน้ารายการใบลา
- แสดงใบลาทั้งหมดจาก data.js เป็นตาราง
- คอลัมน์ หัวข้อ, ผู้ขอลา, ประเภท, วันที่ลา, สถานะ
- สถานะแสดงเป็นป้ายสี รอพิจารณา=เหลือง อนุมัติ=เขียว ไม่อนุมัติ=แดง
- คลิกที่แถวแล้วไปหน้า leave-request-detail.html
- มีแถบเมนูด้านบนที่จะใช้ร่วมกันทุกหน้า ลิงก์ไป
  รายการใบลา, ยื่นใบลา, ประเภทการลา, แดชบอร์ด
- สร้าง css/style.css เก็บสไตล์ที่ใช้ร่วมกันทุกหน้า
- ต้องใช้บนมือถือได้
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ารายการใบลา"
```

**หน้าที่ 2 — ยื่นใบลาใหม่**
```
สร้าง new-leave-request.html หน้ายื่นใบลาใหม่
- ฟอร์มมี หัวข้อ, ประเภทการลา (เลือกจาก leaveTypes), วันที่เริ่ม, วันที่สิ้นสุด, เหตุผล
- กดบันทึกแล้วเพิ่มใบลาใหม่เข้าไปในหน่วยความจำ ตั้งสถานะเป็น รอพิจารณา
- แล้วกลับไปหน้ารายการ
- ใช้แถบเมนูและ css/style.css ชุดเดิม
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ายื่นใบลาใหม่"
```

**หน้าที่ 3 — รายละเอียดใบลา**
```
สร้าง leave-request-detail.html หน้ารายละเอียดใบลา
- แสดงข้อมูลใบลาครบทุก field
- แสดงความเห็นการอนุมัติจาก approvals ของใบนั้น
- มีปุ่มอนุมัติและปุ่มไม่อนุมัติ กดแล้วเปลี่ยนสถานะในหน่วยความจำ
- มีช่องใส่ความเห็นตอนกดอนุมัติหรือไม่อนุมัติ
- ใช้แถบเมนูและ css/style.css ชุดเดิม
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ารายละเอียดใบลา"
```

**หน้าที่ 4 และ 5**
```
สร้างอีก 2 หน้า ทำทีละหน้าและ commit ทีละหน้า

1. leave-types.html หน้าจัดการประเภทการลา
   แสดงรายการประเภทการลา เพิ่มและลบได้ในหน่วยความจำ

2. dashboard.html หน้าแดชบอร์ดสรุป
   นับจำนวนใบลาแยกตามสถานะ แสดงเป็นตัวเลขใหญ่ 3 ช่อง
   ใต้ตัวเลขแสดงรายการใบที่สถานะ รอพิจารณา เรียงจากเก่าสุด
   ตัวเลขต้องนับจากข้อมูลจริงใน data.js ห้ามพิมพ์ตัวเลขค้างไว้

ทั้งสองหน้าใช้แถบเมนูและ css/style.css ชุดเดิม
```

🚩 **ตรวจ:** กดแถบเมนูสลับได้ครบ 5 หน้า · หน้ารายการมีใบลา 5 ใบพร้อมป้ายสี

## ชุดที่ 4 — สร้าง Firebase project และต่อ Firestore ⏱ ~3 นาที

> **ทำด้วยมือก่อน** — ไปที่หน้าเว็บ Firebase สร้างโปรเจกต์ใหม่ แล้วเปิดใช้งาน Firestore
> ⚠️ ตอนเลือกโหมด ให้เลือก **โหมดทดสอบ** และ **จดวันหมดอายุไว้** (ค่าเริ่มต้นหมดอายุใน 30 วัน — สัปดาห์ที่ 7 จะใส่กฎจริงแทน)

```
ผมสร้าง Firebase project และเปิดใช้ Firestore แล้ว
ช่วยต่อเว็บของผมเข้ากับ Firestore ให้หน่อย

1. บอกผมว่าต้องคัดลอกค่าตั้งค่าจากหน้าไหนของ Firebase มาวางตรงไหน
2. สร้างไฟล์สำหรับเก็บค่าตั้งค่านั้น และเชื่อมเข้ากับทุกหน้า
3. อธิบายให้ผมฟังสั้น ๆ ว่าค่าตั้งค่าชุดนี้ปลอดภัยที่จะอยู่ในหน้าเว็บหรือไม่ เพราะอะไร

ยังไม่ต้องแก้หน้าจอ ขอให้ต่อติดก่อน
```

**จะเห็น:** AI บอกให้ไปคัดลอกค่าจากหน้าตั้งค่าของ Firebase · ทำตามแล้ววางกลับมา

## ชุดที่ 5 — ใส่ข้อมูลตัวอย่าง (seed) ลง Firestore ⏱ ~2 นาที

```
ช่วยเขียนสคริปต์ใส่ข้อมูลตัวอย่างลง Firestore ให้ผม
ใช้ข้อมูลชุดเดียวกับที่อยู่ใน js/data.js ตอนนี้เลย

1. โฟลเดอร์ users 3 ไฟล์ ใช้ชื่อไฟล์ u001 u002 u003
2. โฟลเดอร์ leaveTypes 3 ไฟล์ ใช้ชื่อไฟล์ lt001 lt002 lt003
3. โฟลเดอร์ leaveRequests 5 ไฟล์ ใช้ชื่อไฟล์ lr001 ถึง lr005
   ทุกไฟล์ต้องมีทั้ง requesterId กับ requesterName
   และ approverId กับ approverName
   และ leaveTypeId กับ leaveTypeName ให้ครบทุกคู่
   สถานะกระจายให้ครบทั้ง 3 ค่า
4. ใส่ความเห็นลงโฟลเดอร์ย่อย approvals ของใบที่พิจารณาแล้ว
   ใบที่สถานะ ไม่อนุมัติ ต้องมีความเห็นอย่างน้อย 1 อัน

รันแล้วบอกผมว่าใส่สำเร็จกี่ไฟล์
```

🚩 **ตรวจสำคัญ:** เปิด **Firebase Console** (หน้าเว็บสำหรับเปิดดูข้อมูลด้วยตา) → กดเข้าโฟลเดอร์ `leaveRequests` → **เห็นไฟล์ใบลา 5 ไฟล์ด้วยตาตัวเอง** → กดเข้าไปในไฟล์ที่พิจารณาแล้ว แล้วหาโฟลเดอร์ย่อย `approvals` เจอ

## ชุดที่ 6 — หน้ารายการอ่านจากฐานจริง (ตัว R) ⏱ ~2 นาที

> 📌 สัปดาห์ที่ 6 เปลี่ยนเฉพาะ**หน้ารายการ**หน้าเดียว — หน้าอื่นยังใช้ data.js ไปก่อน
> การเพิ่ม/แก้/ลบลงฐานจริง (ตัว C U D) เป็นเนื้อหาของสัปดาห์ที่ 7 **อย่าทำล่วงหน้า**

```
เปลี่ยนหน้ารายการใบลาให้อ่านข้อมูลจาก Firestore แทน js/data.js
เปลี่ยนเฉพาะการอ่านของหน้ารายการหน้าเดียว
หน้าอื่นและไฟล์ data.js ยังไม่ต้องแตะ
เสร็จแล้ว commit ด้วยข้อความว่า "หน้ารายการอ่านจาก Firestore"
```

**จะเห็น:** หน้ารายการแสดงใบลา 5 ใบเหมือนเดิม — แต่คราวนี้มาจากฐานข้อมูลจริง

**พิสูจน์ว่าอ่านจากฐานจริง:** เปิด Firebase Console → แก้ `title` ของ `lr001` ตรงนั้นเลย → รีเฟรชหน้ารายการ → **หัวข้อบนหน้าจอต้องเปลี่ยนตาม**

## 🆘 ติดตรงนี้ให้ทำอย่างไร

| อาการ | ทำอย่างไร |
|---|---|
| **permission denied / ต่อ Firestore ไม่ติด** | ตรวจว่าเปิดใช้ Firestore แล้ว · **ตรวจว่าเลือกโหมดทดสอบตอนสร้าง** และวันหมดอายุยังไม่ถึง (ดูในหน้า Rules) — นี่คือสาเหตุอันดับ 1 |
| ข้อมูลอยู่ใน Console แต่ไม่ขึ้นบนหน้าจอ | ตรวจว่าสะกดชื่อโฟลเดอร์ตรงกันไหม — Firestore แยกตัวพิมพ์เล็ก-ใหญ่ `leaveRequests` กับ `leaverequests` คือคนละโฟลเดอร์ |
| เปิดเว็บไม่ขึ้น / พอร์ตชน | วาง prompt: `เปิดเว็บไม่ขึ้น ช่วยเปลี่ยนไปใช้พอร์ตอื่นแล้วบอกที่อยู่ใหม่ให้ผมด้วย` |
