## ชุดที่ 1 — สร้างโปรเจกต์และหน้าแรก ⏱ ~3 นาที

```
ผมกำลังทำเว็บระบบขอลาออนไลน์ชื่อ LeaveEasy

ข้อกำหนดที่ห้ามเปลี่ยน
- ใช้ HTML, CSS, JavaScript ธรรมดาเท่านั้น ห้ามใช้ framework ใด ๆ
  (ห้าม React, Vue, Vite, TypeScript, bundler)
- ห้ามใช้ไลบรารีจากอินเทอร์เน็ต เขียนเองทั้งหมด
- แยกเป็นไฟล์ .html หนึ่งไฟล์ต่อหนึ่งหน้าจอ
- ข้อความบนหน้าจอทั้งหมดเป็นภาษาไทย
- คอมเมนต์ในโค้ดเป็นภาษาไทย

ช่วยทำให้ผมทีละขั้น
1. เริ่มต้นโปรเจกต์ Node และสร้างไฟล์ .gitignore ที่กัน node_modules
2. git init แล้ว commit แรกด้วยข้อความว่า "เริ่มต้นโปรเจกต์ LeaveEasy"
3. สร้างไฟล์ index.html เป็นหน้าแรก มีเฉพาะหัวข้อ "LeaveEasy ระบบขอลาออนไลน์"
4. ตั้งค่าให้ผมสั่ง npm run dev แล้วเปิดดูในเบราว์เซอร์ได้

ทำทีละข้อ แล้วบอกผมว่าแต่ละข้อเสร็จหรือยัง
```

**จะเห็น:** ข้อความ `added ... packages` วิ่งขึ้นมา ใช้เวลา 1–2 นาที · **ปล่อยให้ทำจนหยุด อย่ากดอะไรขัด**

จากนั้นพิมพ์ `npm run dev` แล้วเปิดที่อยู่ที่มันบอกในเบราว์เซอร์

🚩 **ตรวจ:** เบราว์เซอร์ขึ้นหน้าเว็บที่มีหัวข้อ LeaveEasy

## ชุดที่ 2 — ข้อมูลปลอม ⏱ ~3 นาที

```
ช่วยสร้างไฟล์ js/data.js เก็บข้อมูลปลอมทั้งหมดไว้ที่เดียว
ใช้ชื่อสมมติเท่านั้น ห้ามใช้ข้อมูลจริงของใคร

1. users 3 คน แต่ละคนมี id, name, email, role
   - u001 สมชาย ใจดี  role เป็น employee
   - u002 สมหญิง รักงาน role เป็น manager
   - u003 สมศรี ตั้งใจ role เป็น hr

2. leaveTypes 3 แบบ แต่ละแบบมี id, name
   - lt001 ลาพักร้อน / lt002 ลาป่วย / lt003 ลากิจ

3. leaveRequests 5 ใบ แต่ละใบต้องมี field ครบชุดนี้
   id, title, reason, status,
   requesterId, requesterName,
   approverId, approverName,
   leaveTypeId, leaveTypeName,
   startDate, endDate, createdAt
   ใช้ไอดี lr001 ถึง lr005
   สถานะใช้ได้ 3 ค่าเท่านั้นคือ รอพิจารณา, อนุมัติ, ไม่อนุมัติ
   ให้กระจายสถานะให้หลากหลาย อย่าให้เหมือนกันหมด

4. approvals 3 อัน แต่ละอันมี id, requestId, authorId, authorName, message, createdAt

สำคัญมาก ชื่อ field ทุกตัวต้องสะกดตรงตามที่ผมเขียนไว้ข้างบนเป๊ะ
เพราะสัปดาห์หน้าผมจะย้ายข้อมูลชุดนี้ขึ้นฐานข้อมูลโดยไม่เปลี่ยนชื่อ
```

🚩 **ตรวจ:** เปิดไฟล์ `js/data.js` แล้วเห็นใบลา 5 ใบ ที่มีทั้ง `requesterId` และ `requesterName` อยู่คู่กัน

## ชุดที่ 3 — หน้าจอทั้ง 5 หน้า ⏱ ~5 นาที

> ⚠️ **วางทีละหน้า อย่าวางทั้ง 5 หน้าในคำสั่งเดียว** — สั่งทีเดียวหลายอย่างคือสาเหตุที่โปรเจกต์พังบ่อยที่สุด
> ทำเสร็จหนึ่งหน้า ให้ commit หนึ่งครั้ง แล้วค่อยทำหน้าถัดไป

**หน้าที่ 1 — รายการใบลา**
```
ปรับ index.html ให้เป็นหน้ารายการใบลา
- แสดงใบลาทั้งหมดจาก data.js เป็นตาราง
- คอลัมน์ หัวข้อ, ผู้ขอลา, ประเภท, วันที่ลา, สถานะ
- สถานะแสดงเป็นป้ายสี รอพิจารณา=เหลือง อนุมัติ=เขียว ไม่อนุมัติ=แดง
- คลิกที่แถวแล้วไปหน้า request-detail.html
- มีแถบเมนูด้านบนที่จะใช้ร่วมกันทุกหน้า ลิงก์ไป 5 หน้า
  รายการใบลา, ยื่นใบลา, ประเภทการลา, แดชบอร์ด
- สร้าง css/style.css เก็บสไตล์ที่ใช้ร่วมกันทุกหน้า
- ต้องใช้บนมือถือได้
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ารายการใบลา"
```

**หน้าที่ 2 — ยื่นใบลาใหม่**
```
สร้าง new-request.html หน้ายื่นใบลาใหม่
- ฟอร์มมี หัวข้อ, ประเภทการลา (เลือกจาก leaveTypes), วันที่เริ่ม, วันที่สิ้นสุด, เหตุผล
- กดบันทึกแล้วเพิ่มใบลาใหม่เข้าไปในหน่วยความจำ ตั้งสถานะเป็น รอพิจารณา
- แล้วกลับไปหน้ารายการ
- ใช้แถบเมนูและ css/style.css ชุดเดิม
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ายื่นใบลาใหม่"
```

**หน้าที่ 3 — รายละเอียดใบลา**
```
สร้าง request-detail.html หน้ารายละเอียดใบลา
- แสดงข้อมูลใบลาครบทุก field
- แสดงความเห็นการอนุมัติจาก approvals ของใบนั้น
- มีปุ่มอนุมัติและปุ่มไม่อนุมัติ กดแล้วเปลี่ยนสถานะในหน่วยความจำ
- มีช่องใส่ความเห็นตอนกดอนุมัติหรือไม่อนุมัติ
- ใช้แถบเมนูและ css/style.css ชุดเดิม
เสร็จแล้ว commit ด้วยข้อความว่า "เพิ่มหน้ารายละเอียดใบลา"
```

**หน้าที่ 4 และ 5**
```
สร้างอีก 2 หน้า ทำทีละหน้าและ commit ทีละหน้า

1. leave-types.html หน้าจัดการประเภทการลา
   แสดงรายการประเภทการลา เพิ่มและลบได้ในหน่วยความจำ

2. dashboard.html หน้าแดชบอร์ดสรุป
   นับจำนวนใบลาแยกตามสถานะ แสดงเป็นตัวเลขใหญ่ 3 ช่อง
   ใต้ตัวเลขแสดงรายการใบที่สถานะ รอพิจารณา เรียงจากเก่าสุด
   ตัวเลขต้องนับจากข้อมูลจริงใน data.js ห้ามพิมพ์ตัวเลขค้างไว้

ทั้งสองหน้าใช้แถบเมนูและ css/style.css ชุดเดิม
```

## 🆘 ติดตรงนี้ให้ทำอย่างไร

| อาการ | ทำอย่างไร |
|---|---|
| `npm run dev` ไม่ยอมเปิด / port ชน | วาง prompt: `เปลี่ยนพอร์ตของ npm run dev เป็น 5500 แล้วบอกที่อยู่ใหม่ให้ผมด้วย` |
| AI สร้างโดยใช้ React หรือ framework | หยุดทันที แล้ววาง: `ขอให้ทำใหม่โดยใช้ HTML CSS JavaScript ธรรมดาเท่านั้น ห้ามใช้ framework ใด ๆ` |
| หน้าจอที่สร้างใหม่หน้าตาไม่เข้ากับหน้าเดิม | วาง: `ปรับหน้า ______ ให้ใช้สีและขนาดตัวอักษรชุดเดียวกับ index.html ไฟล์อื่นยังไม่ต้องแตะ` |
| ชื่อผู้ขอลาไม่ขึ้นในตาราง | ตรวจว่าใน `data.js` มี `requesterName` อยู่คู่กับ `requesterId` ไหม ถ้าไม่มีให้สั่งเพิ่ม |
| ทำไปได้ครึ่งทางแล้วพัง | `git log --oneline` หา commit ล่าสุดที่ยังดี แล้วสั่ง AI ให้ย้อนกลับไปจุดนั้น |
| **ใช้เวลาเกิน 20 นาทีแล้วยังไม่จบ** | **หยุด แล้วเรียกผู้ช่วยหรือ TA ทันที** อย่านั่งงมต่อ |
