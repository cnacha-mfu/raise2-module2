# 🛟 ชุดกู้สถานะ (Recovery) — สร้างระบบขึ้นมาใหม่ด้วย prompt

**ใช้เมื่อโปรเจกต์ของกลุ่มพังจนแก้ไม่ไหวกลางคาบ หรือทำสัปดาห์ที่แล้วไม่ทัน**

> 📌 ไฟล์ทั้งหมดเป็น **ตัวอย่างอ้างอิงจากระบบ LeaveEasy** — กลุ่มของคุณให้เปลี่ยนชื่อโฟลเดอร์และชื่อช่องข้อมูลเป็นของโครงงานตัวเอง โครงสร้างขั้นตอนเหมือนกันทุกโครงงาน

---

## ทำไมเป็น prompt ไม่ใช่ไฟล์โค้ดสำเร็จ

| | แจกโค้ดสำเร็จ | **แจกชุด prompt (วิธีที่ใช้)** |
|---|---|---|
| ผู้เรียนได้ฝึกอะไร | คัดลอกไฟล์ ไม่ได้ฝึกอะไร | **ได้ฝึกสั่ง AI ซึ่งคือทักษะของหลักสูตรนี้** |
| โค้ดที่ได้ | ของคนอื่น อ่านไม่คุ้น | ของตัวเอง AI อธิบายให้ฟังได้ |
| เข้ากับโครงงานตัวเอง | ไม่เข้า ต้องแปลงเอง | แก้ชื่อในตัว prompt แล้วใช้กับโครงงานตัวเองได้เลย |
| เวลาที่ใช้ | 2 นาที | 10–15 นาที |

**ยอมแลกเวลา 10 นาที เพื่อให้ผู้เรียนยังได้ฝึกสิ่งที่มาเรียน** — และไฟล์ชุดนี้ยังเป็นตัวอย่าง prompt ที่ดีให้ผู้เรียนดูเป็นแบบด้วย

---

## มีไฟล์อะไรบ้าง

| ไฟล์ | สร้างระบบถึงสถานะไหน | ใช้ตอนเริ่มใบงานที่ |
|---|---|---|
| `leaveeasy-week6-end.md` | หน้าจอครบ 5 หน้า · ข้อมูลปลอม | **ใบงานที่ 2** (สัปดาห์ที่ 7) |
| `leaveeasy-week7-end.md` | + Firestore + CRUD + ขึ้นออนไลน์ | **ใบงานที่ 3** (สัปดาห์ที่ 8) |
| `leaveeasy-week8-end.md` | + ล็อกอิน + Rules + ขึ้นออนไลน์ + Reviewer | **ใบงานที่ 4** (สัปดาห์ที่ 9) |

> 📌 **FixIt ไม่มีชุดกู้** เพราะเป็นระบบของผู้สอน ซึ่งผู้สอนเดินสคริปต์สาธิตเองอยู่แล้วก่อนทุกคาบ

---

## วิธีใช้ (สำหรับผู้เรียน)

1. เปิดไฟล์ของสัปดาห์ที่ต้องการ
2. **สร้างโฟลเดอร์ใหม่** อย่าทับของเก่า (เผื่ออยากกลับไปดู)
   👥 ให้คนในกลุ่มนั่งทำด้วยกันอย่างน้อย 2 คน — คนหนึ่งพิมพ์ อีกคนอ่านและตรวจ
3. เปิด Claude Code ในโฟลเดอร์ใหม่นั้น
4. วาง prompt **ทีละชุด ตามลำดับ** อย่าวางรวดเดียวทั้งไฟล์
5. หลังแต่ละชุด **ตรวจตามที่เขียนไว้ว่า "จะเห็น:"** ก่อนไปชุดถัดไป
6. เสร็จแล้วกลับไปทำใบงานของสัปดาห์นี้ต่อได้เลย

⏱ ใช้เวลาประมาณ 10–15 นาที

---

## เมื่อไรจึงควรใช้ (สำหรับผู้สอนและ TA)

**ให้ใช้เมื่อ** — กลุ่มติดที่ Checkpoint เดิมเกิน 45 นาที · โปรเจกต์พังจนย้อน commit แล้วยังไม่กลับมา · ขาดเรียนสัปดาห์ก่อน

**อย่ารีรอที่จะให้ใช้** — เป้าหมายของคาบคือ **ได้ฝึกเนื้อหาของสัปดาห์นี้** ไม่ใช่ซ่อมของสัปดาห์ที่แล้ว
ปล่อยให้กลุ่มหนึ่งซ่อมของเก่าทั้งคาบ = ทั้งกลุ่มเสียทั้งคาบ และกินคิวถามของกลุ่มอื่นด้วย

> 💡 **ก่อนเปิด Module ผู้สอนควรเดินไฟล์เหล่านี้เองอย่างน้อย 1 รอบ** เพื่อจับเวลาจริงและดูว่า AI สร้างออกมาตรงตามที่คาดไหม แล้วปรับ prompt ให้แม่นขึ้น

---

## ⚠️ ข้อจำกัดที่ต้องรู้

AI สร้างโค้ดไม่เหมือนกันทุกครั้ง **หน้าตาที่ได้จะไม่เหมือนเป๊ะกับของเพื่อน** — ไม่ใช่ความผิดพลาด
สิ่งที่ต้องเหมือนกันคือ **ชื่อโฟลเดอร์และชื่อ field ใน Firestore** เพราะใบงานสัปดาห์ถัดไปอ้างถึงชื่อพวกนี้ตรง ๆ
ทุก prompt ในไฟล์เหล่านี้จึงระบุชื่อไว้ชัดเจนเสมอ — **ห้ามแก้ชื่อเหล่านั้น**
