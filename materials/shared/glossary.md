## 🛠️ เครื่องมือที่ใช้

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **Node.js** | โปรแกรมที่ทำให้โปรเจกต์เว็บของเรารันบนเครื่องได้ |
| **npm** | ตัวติดตั้งชิ้นส่วนสำเร็จรูปที่คนอื่นทำไว้ให้ใช้ |
| **Git / commit** | ปุ่มเซฟแบบมีประวัติ — ย้อนกลับไปจุดที่ยังดีได้เสมอ |
| **GitHub** | ที่เก็บงานสำรองบนคลาวด์ เครื่องพังงานก็ไม่หาย |
| **Repo (Repository)** | โฟลเดอร์โครงงานของเราที่อยู่บน GitHub |
| **`.gitignore`** | รายชื่อไฟล์ที่ห้ามส่งขึ้น GitHub — ใช้กันไฟล์ลับหลุด |
| **Claude Code** | ผู้ช่วย AI ที่อ่านและแก้ไฟล์ในโปรเจกต์เราได้จริง |
| **CLAUDE.md** | คู่มือประจำโครงงานที่ AI อ่านทุกครั้งก่อนเริ่มทำงาน |
| **Firebase Console** | หน้าเว็บสำหรับเปิดดูข้อมูลของเราด้วยตา |

## 🗂️ ข้อมูลและฐานข้อมูล

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **Database / ฐานข้อมูล** | ตู้เก็บข้อมูลที่ยังอยู่แม้ปิดเบราว์เซอร์ |
| **Firestore** | ตู้เก็บข้อมูลของ Firebase ที่เก็บเป็น **โฟลเดอร์และไฟล์** |
| **NoSQL** | ฐานข้อมูลที่เก็บแบบโฟลเดอร์-ไฟล์ ไม่ใช่แบบตาราง Excel |
| 📁 **Collection** | โฟลเดอร์ |
| 📄 **Document** | ไฟล์หนึ่งไฟล์ในโฟลเดอร์ |
| ✏️ **Field** | หัวข้อข้อมูลที่อยู่ข้างในไฟล์ |
| 📁 **Subcollection** | โฟลเดอร์ย่อยที่ซ้อนอยู่ในไฟล์นั้น |
| **Document ID** | ชื่อไฟล์ |
| **CRUD** | เพิ่ม / ดู / แก้ / ลบ ข้อมูล |
| **Seed data** | ข้อมูลตัวอย่างที่ใส่ไว้ทดสอบ |
| **Denormalize (จดซ้ำ)** | จดข้อมูลที่ใช้บ่อยซ้ำไว้ในไฟล์เลย จะได้ไม่ต้องไปเปิดหาที่อื่น |
| **Index** | สารบัญที่ช่วยให้ค้นหาเร็วขึ้น — Firestore ขอให้สร้างเมื่อจำเป็น |
| **DB Schema** | แบบโครงสร้างข้อมูลที่ออกแบบไว้ตั้งแต่ Module 1 ว่าระบบเก็บอะไรบ้าง |

## 🖥️ ส่วนประกอบของระบบ

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **Frontend** | หน้าจอที่ผู้ใช้เห็นและกด |

| **Firebase Hosting** | บริการที่ทำให้เว็บของเรามี URL ที่คนอื่นเปิดได้ |
| **URL** | ที่อยู่เว็บที่ส่งให้คนอื่นเปิด |

## 🔒 ความปลอดภัย

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **Authentication** | ระบบสมัครสมาชิกและล็อกอิน |
| **Role / บทบาท** | ประเภทของผู้ใช้ เช่น พนักงาน กับ หัวหน้า — เห็นและทำได้ไม่เหมือนกัน |
| **Security Rules** | ยามเฝ้าประตูโฟลเดอร์ — บอกว่าใครเปิดอะไรได้ |
| **API Key** | กุญแจประจำตัวสำหรับเรียกใช้บริการภายนอก ห้ามให้ใครเห็น |
| **PDPA** | กฎหมายคุ้มครองข้อมูลส่วนบุคคล — เรียนไปแล้ว Module 1 |

## 🤖 AI และการทำงานกับมัน

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **Prompt** | ข้อความที่เราพิมพ์สั่ง AI |
| **Context** | "ความจำ" ของ AI ในบทสนทนานั้น |
| **Token** | หน่วยนับที่ AI ใช้วัดความยาวข้อความ — กินความจำและกินเงิน |
| **Context Window** | ขนาดความจำสูงสุดของ AI ในหนึ่งบทสนทนา |
| **Model / โมเดล** | รุ่นของ AI — คนละรุ่นให้ผลต่างกัน |
| **Hallucination** | อาการที่ AI ตอบมั่วอย่างมั่นใจ |
| **LLM API** | ช่องทางให้ *ระบบของเรา* เรียกใช้ AI เองตอนผู้ใช้กดปุ่ม |
| **OpenRouter** | บริการที่เราใช้เรียก AI จากระบบของกลุ่ม (สัปดาห์ที่ 8) |
| **Sub-Agent** | ผู้ช่วย AI อีกตัวที่มีหน้าที่เฉพาะ เช่น คนตรวจงาน คนทดสอบ |
| **Reviewer** | ผู้ช่วย AI ที่ *อ่านโค้ด* แล้วบอกว่าตรงไหนน่าจะมีปัญหา |
| **Tester** | ผู้ช่วย AI ที่ *ใช้งานระบบจริง* แล้วบอกว่าตรงไหนพัง |
| **MCP** | ช่องทางที่ทำให้ AI ใช้เครื่องมือภายนอกได้ เช่น เปิดเบราว์เซอร์ |
| **Playwright** | หุ่นยนต์ที่กดใช้งานเว็บของเราแทนคน เพื่อทดสอบว่ายังใช้ได้ |

## 👥 การทำงานเป็นกลุ่ม

| ศัพท์ | พูดแบบภาษาคน |
|---|---|
| **คนคุมคีย์บอร์ด** | คนที่แชร์หน้าจอและพิมพ์ในรอบนั้น — **ต้องหมุนเปลี่ยนคนทุก Checkpoint** |
| **pull / ดึงก่อนเริ่ม** | ดึงงานล่าสุดของเพื่อนลงมาก่อนลงมือ — **ไม่ดึงก่อน งานจะชนกัน** |
| **push / ส่งขึ้น** | ส่งงานของเราขึ้น GitHub ให้เพื่อนเห็น |
| **conflict / งานชนกัน** | สองคนแก้ไฟล์เดียวกันคนละแบบ ระบบเลยไม่รู้จะเอาอันไหน |
