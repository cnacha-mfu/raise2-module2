## 4. โครงสร้างข้อมูลบน Firestore

> 📁 โฟลเดอร์ = Collection · 📄 ไฟล์ = Document · ✏️ ข้อมูลในไฟล์ = Field
> **โครงสร้างนี้สร้างจริงบน Firestore ไว้แล้วตั้งแต่สัปดาห์ที่ 6** — กรอกให้ตรงกับของจริงที่เห็นใน Firebase Console โดยเทียบกับ ERD ที่ออกแบบไว้ Module 1

```
📁 ⟨ชื่อโฟลเดอร์⟩/
   📄 ⟨ตัวอย่างไอดี⟩ { ⟨ช่องข้อมูล⟩, ⟨ช่องข้อมูล⟩, ... }

📁 ⟨ชื่อโฟลเดอร์หลัก⟩/
   📄 ⟨ตัวอย่างไอดี⟩ {
        ⟨ช่องข้อมูล⟩,
        ⟨ช่องที่ชี้ไปโฟลเดอร์อื่น⟩Id,   ⟨ช่องที่จดชื่อซ้ำไว้⟩Name,
        createdAt
      }
      📁 ⟨โฟลเดอร์ย่อย⟩/
         📄 ⟨ตัวอย่างไอดี⟩ { ⟨...⟩ }
```

## 5. ข้อตกลงของโครงงานนี้

**สั่งครั้งเดียว AI จำได้ทั้งโครงงาน**

- ข้อความบนหน้าจอทั้งหมดเป็น **ภาษาไทย**
- ⚠️ ชื่อ field ใน Firestore **ต้องสะกดตรงตามหัวข้อ 4 เป๊ะ** — Firestore แยกตัวพิมพ์เล็ก-ใหญ่
- ทุกหน้าจอต้องใช้บนมือถือได้
- ทุกจุดที่ต้องรอ ต้องมีข้อความบอกว่ากำลังโหลดอยู่
- ข้อความแจ้งข้อผิดพลาดต้องเป็นภาษาไทยที่บอกว่า **เกิดอะไรขึ้น และควรทำอย่างไรต่อ**
- ตัวเลขบนแดชบอร์ดต้องนับจากข้อมูลจริงเสมอ **ห้ามใส่ตัวเลขค้างไว้ในโค้ด**
- แก้ทีละอย่าง แล้วให้ผมตรวจก่อนทำต่อ
