# 🧪 ตั้งค่า Playwright MCP — คู่มือติดตั้งล่วงหน้า

**ใช้ในสัปดาห์ที่ 9 · แต่ต้องติดตั้งให้เสร็จตั้งแต่ช่วงทำโครงงานของสัปดาห์ที่ 8**

> **Playwright คืออะไร** — หุ่นยนต์ที่กดใช้งานเว็บของเราแทนคน เปิดเบราว์เซอร์จริง กดปุ่มจริง กรอกฟอร์มจริง แล้วบอกว่าตรงไหนพัง
> **MCP คืออะไร** — ช่องทางที่ทำให้ Claude ใช้เครื่องมือภายนอกได้ ในที่นี้คือทำให้ Claude สั่งหุ่นยนต์ตัวนี้ได้

⏱ ใช้เวลาประมาณ 15 นาที · **ทำที่บ้านก่อนถึงคาบ อย่ารอทำในคาบ**
🆘 ถ้าติดเกิน 15 นาที **ให้หยุดแล้วจองคิวปรึกษาทันที** อย่านั่งงมเอง

---

## ขั้นที่ 1 — ตรวจว่าเครื่องพร้อม

เปิด terminal ในโฟลเดอร์โครงงานของคุณ แล้วพิมพ์

```
node --version
```

**จะเห็น:** ตัวเลขรุ่นขึ้นมา 1 บรรทัด เช่น `v20.11.0`

🆘 ถ้าขึ้นว่าไม่รู้จักคำสั่ง → ปิดเปิด terminal ใหม่ · ถ้ายังไม่ได้ให้เรียกผู้ช่วย

---

## ขั้นที่ 2 — ให้ Claude Code ติดตั้งให้

เปิด Claude Code ในโฟลเดอร์โครงงาน แล้ววาง prompt นี้

```
ช่วยติดตั้ง Playwright ในโปรเจกต์นี้ให้ผมหน่อย
1. ติดตั้ง Playwright และดาวน์โหลดเบราว์เซอร์ที่ต้องใช้
2. สร้างไฟล์ตั้งค่าให้ทดสอบกับเว็บของผมที่อยู่บน Firebase Hosting
3. อธิบายให้ผมฟังสั้น ๆ ว่าไฟล์ที่สร้างมาแต่ละไฟล์ทำหน้าที่อะไร
ทำทีละขั้น แล้วบอกผมว่าแต่ละขั้นเสร็จหรือยัง
```

**จะเห็น:** ข้อความ `added ... packages` วิ่งขึ้นมา แล้วตามด้วยการดาวน์โหลดเบราว์เซอร์ (ก้อนนี้ใหญ่ ใช้เวลา 2–5 นาที) · **ปล่อยให้ทำจนหยุด อย่ากดอะไรขัด**

---

## ขั้นที่ 3 — เชื่อม MCP เข้ากับ Claude Code

วาง prompt นี้ต่อ

```
ช่วยเชื่อม Playwright MCP เข้ากับ Claude Code ในโปรเจกต์นี้ให้ด้วย
แล้วบอกผมว่าต้องปิดเปิดโปรแกรมใหม่หรือเปล่า
```

จากนั้น **ปิดแล้วเปิด Claude Code ใหม่** ตามที่มันบอก

---

## ขั้นที่ 4 — 🚩 ตรวจสถานะด้วยคำสั่ง `/mcp` (ทำก่อนเสมอ)

พิมพ์คำสั่งนี้ในหน้าต่าง Claude Code แล้วกด Enter

```
/mcp
```

**จะเห็น:** รายชื่อ MCP server ที่เครื่องคุณตั้งไว้ พร้อม**สถานะของแต่ละตัว** · เทียบกับตารางนี้แล้วทำตามช่องขวา

| สิ่งที่เห็นบนจอ | แปลว่า | ทำอย่างไรต่อ |
|---|---|---|
| **ไม่มี server เลยสักตัว** | **ยังไม่ได้ติดตั้ง** | กลับไปทำขั้นที่ 2 และ 3 ใหม่ · อย่าไปไล่แก้อย่างอื่น |
| **เชื่อมต่อแล้ว** | พร้อมใช้งาน | ไปขั้นที่ 5 ต่อได้เลย |
| **ต้องยืนยันตัวตนก่อน** | ยังไม่ได้ยืนยันตัวตน | เลือก server นั้น แล้วทำตามที่หน้าจอบอก |
| **เชื่อมต่อไม่สำเร็จ** | ตั้งไว้แล้วแต่ต่อไม่ติด | เลือก server นั้นแล้วสั่งเชื่อมใหม่ · ยังไม่ได้ให้ปิดแล้วเปิด Claude Code |
| **รอการอนุมัติ** | ยังไม่ได้อนุมัติให้ใช้ | อนุมัติให้ใช้งาน server นั้นก่อน |

> 💡 **แถวแรกมีค่าที่สุด** — มันแยกให้คุณเห็นระหว่าง *ยังไม่ได้ติดตั้ง* กับ *ติดตั้งแล้วแต่เชื่อมไม่ติด*
> สองอย่างนี้แก้คนละทางกัน ถ้าไม่ถามด้วย `/mcp` ก่อน คุณจะไล่แก้ผิดจุด

> ⚠️ **คำสั่งของ Claude Code เปลี่ยนได้ตามเวอร์ชัน ถ้าพิมพ์แล้วไม่ได้ผล ให้พิมพ์ `/help` ดูรายการที่ใช้ได้จริงในเครื่องคุณ**
> ถ้าหน้าจอของคุณไม่เหมือนของเพื่อนเป๊ะ ถือว่าปกติ เพราะแต่ละคนติดตั้งคนละวัน · ให้ดูที่ **สถานะ** เป็นหลัก

## ขั้นที่ 5 — 🚩 ยืนยันซ้ำด้วยการสั่งเปิดเบราว์เซอร์จริง

วาง prompt นี้ โดยเปลี่ยน `⟨URL ของคุณ⟩` เป็นที่อยู่เว็บจริงของคุณ

```
ช่วยเปิดเบราว์เซอร์ไปที่ ⟨URL ของคุณ⟩
แล้วบอกผมว่าคุณเห็นอะไรบนหน้าจอบ้าง
```

**ถ้าเชื่อมสำเร็จ จะเห็น 2 อย่างนี้**
1. **หน้าต่างเบราว์เซอร์เปิดขึ้นมาเอง** โดยที่คุณไม่ได้กด (มักมีแถบบอกว่ากำลังถูกควบคุมโดยโปรแกรมอัตโนมัติ)
2. Claude เล่าให้ฟังว่าเห็นอะไรบนหน้าเว็บของคุณ

✅ **ถึงตรงนี้ถือว่าพร้อมสำหรับสัปดาห์ที่ 9 แล้ว** — โพสต์ screenshot **ผลของคำสั่ง `/mcp` ที่ขึ้นว่าเชื่อมต่อแล้ว** และ **หน้าต่างเบราว์เซอร์ที่เปิดเอง** ลงในแชทกลาง

## 🆘 ติดตรงนี้ให้ทำอย่างไร

| อาการ | ทำอย่างไร |
|---|---|
| ดาวน์โหลดเบราว์เซอร์ค้างนาน | ก้อนนี้ใหญ่จริง รอได้ถึง 10 นาที · ถ้าเกินนั้นให้หยุดแล้วสั่งใหม่ |
| ปิดเปิด Claude Code แล้วยังไม่เห็นเครื่องมือ | ตรวจว่าเปิด Claude Code **ในโฟลเดอร์โครงงาน** ไม่ใช่โฟลเดอร์อื่น |
| **เชื่อมไม่ติด ไม่รู้ว่าติดตรงไหน** | **พิมพ์ `/mcp` ดูก่อนว่าสถานะเป็นแบบไหน** แล้วทำตามช่องขวาของตารางในขั้นที่ 4 |
| **พิมพ์ `/mcp` แล้วไม่มีอะไรขึ้น** | **คำสั่งของ Claude Code เปลี่ยนได้ตามเวอร์ชัน ถ้าพิมพ์แล้วไม่ได้ผล ให้พิมพ์ `/help` ดูรายการที่ใช้ได้จริงในเครื่องคุณ** · แล้วข้ามไปยืนยันด้วยขั้นที่ 5 แทน |
| เบราว์เซอร์ไม่เปิดขึ้นมา | ดูสถานะจาก `/mcp` ก่อน · ถ้าขึ้นว่าเชื่อมต่อแล้วแต่ยังไม่เปิด ให้วาง prompt นี้: `ช่วยตรวจว่า Playwright MCP เชื่อมต่อสำเร็จหรือยัง ถ้ายังให้บอกผมว่าติดตรงไหน` |
| เปิดได้แต่หน้าเว็บว่าง | ตรวจว่า URL ถูกต้องและเปิดจากเบราว์เซอร์ปกติได้จริงก่อน |
| ติดตั้งไม่ผ่านเพราะเน็ตบริษัท | ลองที่บ้านหรือใช้เน็ตมือถือ · ถ้ายังไม่ได้ให้แจ้งผู้สอนก่อนวันเสาร์ |
| **ติดเกิน 15 นาที** | **หยุด แล้วจองคิวปรึกษา** — ผู้สอนมีไฟล์ตั้งค่าสำเร็จรูปให้ |

## 📌 สำหรับผู้สอน

- เตรียม **ไฟล์ตั้งค่าสำเร็จรูป** ไว้แจกคนที่ติดตั้งไม่ผ่าน — ให้คัดลอกไปวางแล้วใช้ได้เลย
- ตรวจใน **Consult วันอาทิตย์ก่อนสัปดาห์ที่ 9** ว่าใครยังไม่ผ่านขั้นที่ 4 และขั้นที่ 5
- ให้ผู้เรียนส่ง **screenshot ผลของ `/mcp`** มาด้วย จะดูออกทันทีว่าใคร *ยังไม่ได้ติดตั้ง* กับใคร *ติดตั้งแล้วแต่เชื่อมไม่ติด*
- ⚠️ **ห้ามปล่อยให้มีคนติดตั้งไม่เสร็จเข้าคาบสัปดาห์ที่ 9** — จะกินคิวถามทั้งคาบและทำให้คนอื่นเสียเวลาตาม
