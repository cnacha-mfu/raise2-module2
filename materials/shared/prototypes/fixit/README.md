# 🎬 FixIt — เว็บ prototype แบบคลิกได้

prototype ประกอบการสอน **ADT-RAISE Batch 2 · Module 2 · สัปดาห์ที่ 6** — ให้ผู้เรียนเปิดดู "ปลายทาง" ของระบบแจ้งซ่อมออนไลน์ก่อนลงมือพัฒนาจริง

- **ข้อกำหนดระบบฉบับเต็ม:** [`../../specs/fixit-spec.md`](../../specs/fixit-spec.md)
- **ระบบคู่ขนาน (ใช้ใน Lab):** [`../leaveeasy/`](../leaveeasy/) — โครงหน้าจอเดียวกัน 1:1 ต่างกันที่โจทย์และสี

## จุดตั้งใจเชิงการสอน

ข้อมูลทั้งหมดเป็นข้อมูลปลอมในหน่วยความจำ (ตัวแปรใน `js/data.js`) — **ไม่มีฐานข้อมูล ไม่มี localStorage** กรอกอะไรลงไปแล้วกดรีเฟรช ข้อมูลจะกลับเป็นชุดเดิมทั้งหมด นี่คือสิ่งที่ Module 2 จะแก้ ด้วยการต่อ Firestore เข้ามาให้ระบบ "จำได้"

## วิธีเปิดดู

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์โดยตรง หรือเปิดผ่าน GitHub Pages ได้ทันที — ไม่ต้องติดตั้งอะไร ไม่มีขั้นตอน build

## หน้าจอทั้งหมด

| ไฟล์ | หน้าจอ |
|---|---|
| `index.html` | หน้าแรก รวมลิงก์ทุกหน้า |
| `tickets.html` | รายการใบแจ้งซ่อม (ป้ายสถานะ 4 สี) |
| `new-ticket.html` | ฟอร์มแจ้งซ่อมใหม่ |
| `ticket-detail.html` | รายละเอียด + เปลี่ยนสถานะ + ความคืบหน้า |
| `categories.html` | จัดการหมวดหมู่ปัญหา |
| `dashboard.html` | แดชบอร์ดสรุป (นับจากข้อมูลจริงในหน่วยความจำ) |

ชื่อคนทุกชื่อเป็นชื่อสมมติ
