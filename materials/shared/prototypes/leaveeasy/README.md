# 🔧 LeaveEasy — เว็บ prototype แบบคลิกได้

prototype ประกอบการสอน **ADT-RAISE Batch 2 · Module 2 · สัปดาห์ที่ 6** — ให้ผู้เรียนเปิดดู "ปลายทาง" ของระบบขอลาออนไลน์ก่อนลงมือพัฒนาจริงในคาบ Lab

- **ข้อกำหนดระบบฉบับเต็ม:** [`../../specs/leaveeasy-spec.md`](../../specs/leaveeasy-spec.html)
- **ระบบคู่ขนาน (ใช้สาธิตในคาบบรรยาย):** [`../fixit/`](../fixit/) — โครงหน้าจอเดียวกัน 1:1 ต่างกันที่โจทย์และสี

## จุดตั้งใจเชิงการสอน

ข้อมูลทั้งหมดเป็นข้อมูลปลอมในหน่วยความจำ (ตัวแปรใน `js/data.js`) — **ไม่มีฐานข้อมูล ไม่มี localStorage** กรอกอะไรลงไปแล้วกดรีเฟรช ข้อมูลจะกลับเป็นชุดเดิมทั้งหมด นี่คือสิ่งที่ Module 2 จะแก้ ด้วยการต่อ Firestore เข้ามาให้ระบบ "จำได้"

## วิธีเปิดดู

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์โดยตรง หรือเปิดผ่าน GitHub Pages ได้ทันที — ไม่ต้องติดตั้งอะไร ไม่มีขั้นตอน build

## หน้าจอทั้งหมด

| ไฟล์ | หน้าจอ |
|---|---|
| `index.html` | หน้าแรก รวมลิงก์ทุกหน้า |
| `leave-requests.html` | รายการใบลา (ป้ายสถานะ 3 สี) |
| `new-leave-request.html` | ฟอร์มยื่นใบลาใหม่ |
| `leave-request-detail.html` | รายละเอียด + อนุมัติ/ไม่อนุมัติ + ความเห็น |
| `leave-types.html` | จัดการประเภทการลา |
| `dashboard.html` | แดชบอร์ดสรุป (นับจากข้อมูลจริงในหน่วยความจำ) |

ชื่อคนทุกชื่อเป็นชื่อสมมติ
