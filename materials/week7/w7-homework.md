## 📋 ทำตามนี้

### A — CLAUDE.md แล้วขึ้น GitHub *(เหมือนใบงานส่วน A)*

- พิมพ์ `/init` → **เปิดอ่านแล้วตอบให้ได้ว่าอะไรขาด** → สั่งเติมชื่อโฟลเดอร์ Firestore สถานะทั้งหมด และข้อห้ามของโปรเจกต์
- สร้าง `.gitignore` **ก่อน** push เสมอ แล้วสั่งให้ Claude *"แสดงรายการไฟล์ที่กำลังจะส่งขึ้น GitHub"* → **อ่านเองว่ามีไฟล์คีย์ไหม**
- push ขึ้น GitHub

### B — ปุ่มเพิ่ม แก้ ลบ ที่ทำงานจริง *(เหมือนใบงานส่วน B)*

```prompt
ผมอยากให้ฟอร์ม<ชื่อหน้าของคุณ> บันทึกลง Firestore จริง
ตั้งสถานะเริ่มต้นเป็น <สถานะแรกของคุณ> แล้วกลับไปหน้ารายการ
ขอดูแผนก่อน อย่าเพิ่งลงมือ
```

ทำต่อให้ครบ 3 อย่าง — **เพิ่ม** · **แก้สถานะ** (แก้เฉพาะช่องสถานะ ช่องอื่นห้ามแตะ) · **ลบ** (ต้องถามยืนยันก่อนทุกครั้ง)

✅ **พิสูจน์:** กรอกใหม่ 1 รายการ → ปิดเบราว์เซอร์ → เปิดใหม่ → ข้อมูลยังอยู่

### C — ล็อกอิน + 🔒 กุญแจประตูหน้าบ้าน *(เหมือนใบงานส่วน C)*

- Firebase Console → Authentication → เปิด Email/Password
- ทำให้ครบ 5 ข้อ: สมัคร · เข้า · ออก · ไม่ล็อกอินเด้งไปหน้าเข้าสู่ระบบ · **รายการใหม่ต้องบันทึก uid ของคนที่ล็อกอิน**

```prompt
ช่วยเขียน Firestore Security Rules กฎข้อเดียว
คือต้องล็อกอินก่อนจึงอ่านหรือเขียนได้
เขียนไฟล์มาให้ผมอ่านก่อน อย่าเพิ่ง deploy
```

✅ **ทดสอบ:** เปิดหน้าต่างส่วนตัว (Incognito) แล้วเข้าโดยไม่ล็อกอิน → ต้องขึ้น `permission-denied`

> ⚠️ กฎขั้นต่ำนี้ **ยังไม่พอ** — ใครสมัครก็ยังอ่านของคนอื่นได้ · **ห้ามใส่ข้อมูลจริงของคนอื่นจนกว่าจะจบสัปดาห์ที่ 8**

### D — ขึ้นออนไลน์ *(เหมือนใบงานส่วน D)*

Deploy เว็บ **พร้อมกับกฎ** ในรอบเดียว → ได้ URL ลงท้าย `.web.app` → ให้เพื่อนลองเปิดจากเครื่องเขา

> 🔒 **ห้าม deploy โดยไม่มีกฎขั้นต่ำ** — ปล่อยขึ้นออนไลน์โดยเปิดข้อมูลกว้าง คือการทำข้อมูลรั่วจริง
