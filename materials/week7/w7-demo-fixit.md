# บล็อก A — CLAUDE.md ด้วย `/init` ⏱ 6 นาที

### ขั้นที่ 1 — `/init` ร่างให้ แล้วเราอ่านตรวจ ⏱ 6 นาที

> 📍 สไลด์ **12** *(🎬 /init กับ FixIt แล้วตรวจว่าอะไรขาด)* → สาธิต → กลับเข้าสไลด์ **13** *(✅ ช่วงที่ 1)*

**พูดว่า:** "สัปดาห์ที่แล้วผมต้องอธิบาย FixIt ให้ Claude ฟังใหม่ทุกบทสนทนา วันนี้เขียนไว้ครั้งเดียวจบ และผมจะไม่พิมพ์เองสักตัวอักษร"

**ทำ:** เปิด Claude Code ในโฟลเดอร์ `fixit-demo` → **พิมพ์ `/init` ให้เห็นชัดก่อนกด Enter**

**ผู้เรียนจะเห็น:** Claude ไล่อ่านไฟล์ แล้ว**แสดงร่าง CLAUDE.md พร้อมถามก่อนบันทึก** — ยังไม่มีไฟล์เกิดจนกว่าเราจะตอบ

> ⚠️ **ต้องพูดให้ครบ:** "`/init` ทำแทนเราได้สองจังหวะแรกเท่านั้น **จังหวะที่สาม อ่านแล้วบอกว่าอะไรขาด ยังเป็นงานของเรา**"
> ⚠️ **ถ้า `/init` ไม่ได้ผลในเวอร์ชันนี้** อย่าไล่แก้สด — พูดประโยค `/help` ประจำคาบ แล้วใช้ prompt สำรอง: *"อ่านไฟล์ในโปรเจกต์นี้ แล้วร่าง CLAUDE.md ให้ผมดูก่อน ภาษาไทย ไม่เกิน 1 หน้า อย่าเพิ่งบันทึก"*

**📖 จังหวะที่ 3 — อ่านออกเสียงแล้วชี้ว่าอะไรขาด ⭐** ร่างจาก `/init` มักขาดชุดนี้

| สิ่งที่ต้องมี | ร่างมักเป็นอย่างไร |
|---|---|
| โครงสร้างข้อมูล Firestore ชื่อช่องครบ | ไม่ครบ หรือสะกดไม่ตรง spec |
| รายการความสามารถ (API List) | ไม่มี เพราะเดาความตั้งใจเราไม่ได้ |
| ข้อตกลง (สถานะ 4 ค่า · ข้อความไทย) | มักไม่มี |
| สิ่งที่ห้ามทำ | ไม่มี หรือกว้างเกิน |

**prompt ที่ใช้ (จังหวะที่ 3):**
> ขอเพิ่มหัวข้อ โครงสร้างข้อมูลบน Firestore โดยคัดจากหัวข้อ 5.2 ของไฟล์ fixit-spec.md มาทั้งชุด ห้ามเปลี่ยนชื่อช่อง
> ขอเพิ่มหัวข้อ ข้อตกลงของโครงงาน กับ สิ่งที่ห้ามทำ และ API List จากหัวข้อ 3 ของ spec
> เขียนภาษาไทย ไม่เกิน 1 หน้า ที่เหลือโอเค

**prompt ที่ใช้ (จังหวะที่ 4):**
> โอเคแล้ว บันทึกเป็น CLAUDE.md ที่โฟลเดอร์บนสุดได้เลย

จากนั้น *"ปักหมุดเก็บงานให้ผม ตั้งข้อความว่า เพิ่ม CLAUDE.md คู่มือประจำโครงงาน"*

**ผู้เรียนจะเห็น:** ไฟล์ `CLAUDE.md` ที่โฟลเดอร์บนสุด · หัวข้อภาษาไทย · ชื่อช่องตรง spec ทุกตัว

**ชี้ให้ดูตรงนี้:** ไฟล์อยู่**โฟลเดอร์บนสุด** (วางผิดที่ Claude ไม่อ่าน) · ชี้บรรทัดชื่อช่อง — "ตั้งแต่นาทีนี้ Claude จะสะกด `reporterName` ชุดเดียวกันทุกบทสนทนา" · ปิดท้าย "ผมไม่ได้พิมพ์ไฟล์นี้เองสักตัวอักษร ผมอ่านแล้วบอกว่าอะไรขาด"

**เชื่อมกับ LeaveEasy:** "ของ LeaveEasy คือคู่มือที่มี `leaveRequests` และสถานะ 3 ค่า — **แล้วคู่มือของหัวข้อคุณเขียนโครงสร้างว่าอะไร**"

> 🆘 ร่างยาวเกิน 3 หน้า → *"ตัด CLAUDE.md ให้เหลือไม่เกิน 1 หน้า เก็บหัวข้อเดิมครบ"* · ยังไม่ดี เปิดไฟล์จาก `fixit-week7-end` มาใช้แล้วเดินต่อ

# บล็อก B — CRUD ครบ 4 ตัว ⏱ 26 นาที

> 🔑 **พูดก่อนเริ่มบล็อกนี้:** "ผมจะทำทีละตัว ตรวจ Console ทุกตัว commit ทุกตัว — สั่งสามตัวรวดเดียวแล้วพัง ผมจะไม่รู้ว่าพังตัวไหน"

### ขั้นที่ 2 — C: หน้าแจ้งซ่อมใหม่ บันทึกลงฐานจริง ⏱ 10 นาที

> 📍 สไลด์ **20** *(🎬 C: แจ้งซ่อมใบใหม่ ลงฐานจริง)* → สาธิต → กลับเข้าสไลด์ **21** *(U — แก้ไข)*

**พูดว่า:** "ปุ่มบันทึกตอนนี้ยังหลอกอยู่ กดแล้วเหมือนบันทึก แต่รีเฟรชแล้วหาย วันนี้ต่อสายจริง"

**prompt ที่ใช้ (จังหวะที่ 1):**
> เปลี่ยนหน้าแจ้งซ่อมใหม่ให้บันทึกลง Firestore จริง
> ช่วยเขียนแผนให้ผมดูก่อน อย่าเพิ่งลงมือ

**ผู้เรียนจะเห็น:** แผน 4–5 ข้อ ยังไม่มีโค้ด

#### 💥 จุดที่แผนมาผิด — จงใจให้ผู้เรียนเห็น

| แผนมักขาด | ทำไมสำคัญ |
|---|---|
| ชื่อที่จดซ้ำ (`reporterName` `categoryName`) | ขาดแล้วหน้ารายการขึ้นรหัสแทนชื่อ |
| ตั้ง `status` = แจ้งใหม่ · `createdAt` อัตโนมัติ | ผู้ใช้ห้ามเลือกสถานะเอง |
| ตรวจข้อมูลก่อนบันทึกเมื่อกรอกไม่ครบ | กันขยะเข้าฐาน |

**พูดตอนนี้:** "ถ้าผมพิมพ์โอเคตอนนี้ บ่ายนี้หน้ารายการผมจะขึ้น u001 แทนชื่อสมชาย — จังหวะที่สามมีไว้จับตรงนี้"

**prompt ที่ใช้ (จังหวะที่ 3 ⭐):**
> ขอบันทึกชื่อที่จดซ้ำให้ครบทุกคู่ตามโครงสร้างใน CLAUDE.md
> ตั้งสถานะ แจ้งใหม่ กับเวลาที่แจ้ง ให้อัตโนมัติ
> กรอกไม่ครบต้องเตือนเป็นภาษาไทยและไม่บันทึก ที่เหลือโอเค

**prompt ที่ใช้ (จังหวะที่ 4):**
> แผนโอเคแล้ว ลงมือได้ ทำทีละข้อ เสร็จข้อไหนบอกผมก่อน

**ทำต่อ (ตรวจด้วยตา 3 จุด):** ① กรอกใบใหม่ "ปลั๊กไฟห้องประชุมชำรุด" หมวดไฟฟ้า → บันทึก · ② Console → รีเฟรช → เปิด `tickets` · ③ กรอกใหม่โดย**เว้นหัวข้อว่าง** → บันทึก

**ผู้เรียนจะเห็น:** ① ใบใหม่โผล่ในหน้ารายการ · ② Console มีไฟล์ใหม่ มี `reporterName` และ `status: "แจ้งใหม่"` · ③ ขึ้นเตือนภาษาไทย และ**ไม่มีไฟล์ขยะใน Console**

**ชี้ให้ดูตรงนี้:** ชี้ไฟล์ใหม่ใน Console — "หน้าจอโกหกได้ ตรงนี้โกหกไม่ได้ ผมจะเปิดดูแบบนี้หลังทุกตัวของ CRUD"

**ทำต่อ:** commit `"ตัว C แจ้งซ่อมใหม่บันทึกลงฐานจริง"`

**เชื่อมกับ LeaveEasy:** "ตัว C ของ LeaveEasy คือยื่นใบลาใหม่ ที่ต้องบันทึก `requesterName` คู่กับ `requesterId` — **แล้วตัว C ของคุณคือฟอร์มอะไร**"

> 🆘 กดบันทึกแล้วเงียบ → กด F12 อ่าน error บรรทัดแรกออกเสียง · ถ้าเป็น permission denied = โหมดทดสอบหมดอายุ ต่ออายุที่หน้า Rules แล้วบอกห้องว่า "บ่ายนี้จะมีคนเจอ ใบงานมีทางออกให้แล้ว"

**ชี้ให้ดูตรงนี้:** "สองภาพนี้คู่กันคือหลักฐานว่ากุญแจทำงาน คนในบ้านใช้ได้ คนแปลกหน้าเข้าไม่ได้ — และนี่คือครึ่งแรกของ Checkpoint 3 บ่ายนี้"

**เชื่อมกับ LeaveEasy:** "ตอนนี้คนไม่ล็อกอินเปิดดูใบลาไม่ได้แล้ว — แต่**ยังไม่ปลอดภัยจริง ใครสมัครใหม่ก็อ่านได้หมด** สัปดาห์หน้าปิดรายห้อง ระหว่างนี้ห้ามใส่ข้อมูลจริงของใคร"

**ชี้ให้ดูตรงนี้:** "ผมกวาดตาดูหน้านี้ทุกครั้งหลัง push ใช้ 10 วินาที กันเรื่องใหญ่ได้ — เผลอ push คีย์ขึ้นไป ให้**เพิกถอนคีย์ก่อน** แล้วค่อยลบไฟล์ ลบอย่างเดียวไม่พอ"

**เชื่อมกับ LeaveEasy:** "ภาพหน้า repo แบบนี้คือ Checkpoint 1 ของบ่ายนี้"

**พูดตอนพัง:** "GitHub ไม่ยอมให้ผมทับงานเพื่อน มันบอกให้ไปดึงของล่าสุดมาก่อน — นี่คือระบบป้องกัน ไม่ใช่ความเสียหาย"

**วิธีกู้ · prompt ที่ใช้:**
> ผม pull แล้วมีไฟล์งานชนกัน ช่วยอธิบายว่าฝั่งไหนแก้อะไร
> แล้วรวมให้เก็บของทั้งสองฝั่ง เสร็จแล้วให้ผมดูก่อน commit

**ทำต่อ:** เปิดไฟล์ให้ห้องเห็นว่ามีข้อความ**ทั้งสองฝั่ง** → อ่านไฟล์ที่รวมแล้ว → *"โอเคแล้ว ปักหมุดแล้ว push ขึ้นไปให้ผม"* → รีเฟรชหน้า GitHub

**ผู้เรียนจะเห็น:** push ผ่าน · บน GitHub เห็นข้อตกลง**ทั้งสองบรรทัด**ครบ

**ชี้ให้ดูตรงนี้:** "งานอยู่ครบทั้งสองฝั่ง ระบบไม่ตัดสินใจแทนเรา มันถามว่าจะเก็บแบบไหน · และผมไม่ได้พิมพ์คำสั่ง git สักตัว ผมเล่าอาการให้ Claude ฟังเฉย ๆ — สิ่งที่ผมทำเองคือ commit ไว้ก่อน"

**เชื่อมกับ LeaveEasy:** "บ่ายนี้ใบงานไม่ได้ให้ซ้อมทำให้ชนเอง เพราะเวลาไม่พอ — แต่วันไหนเจอคำว่า conflict ให้ทำแบบที่เพิ่งเห็น commit ก่อน แล้วเล่าอาการให้ Claude ฟัง"

> 🆘 pull แล้วขึ้นคำถามเรื่องวิธีรวม (rebase/merge) → เลือกค่าเริ่มต้นแล้วไปต่อ อย่าอธิบายลึกหน้าห้อง

# บล็อก F — Deploy ฉากจำของเช้า ⏱ 9 นาที

### ขั้นที่ 10 — FixIt ขึ้น URL จริงต่อหน้าห้อง ⏱ 9 นาที

> 📍 สไลด์ **59** *(🎬 FixIt ขึ้น URL จริง ต่อหน้าห้อง)* → สาธิต → กลับเข้าสไลด์ **60** *(!! ระบบของเราออนไลน์แล้ว)*

**พูดว่า:** "นาทีที่ผมรอมาทั้งเช้า — ระบบที่อยู่ในเครื่องเราคนเดียวยังไม่นับว่าเป็นระบบ เอามันออกสู่โลกกัน"

**prompt ที่ใช้:**
> ช่วยนำเว็บนี้ขึ้น Firebase Hosting บอกผมทีละขั้นว่าต้องพิมพ์อะไร
> และ deploy Security Rules ขึ้นไปด้วยในรอบเดียวกัน
> เสร็จแล้วบอก URL ที่ผมส่งให้คนอื่นเปิดได้

**ทำ:** พิมพ์ตามทีละขั้น อ่านออกเสียงทุกคำสั่งก่อนกด · รอ 1–2 นาที

**ผู้เรียนจะเห็น:** `Deploy complete!` และบรรทัด **Hosting URL** ลงท้าย `.web.app`

**ทำต่อ (ฉากจำ — อย่ารีบ):** ① เปิด URL เห็นหน้าเข้าสู่ระบบ · ② **หยิบโทรศัพท์เปิด URL เดียวกันให้เห็นหน้าจอ** · ③ **วาง URL ในแชท "ทุกคนเปิดตามเดี๋ยวนี้ เปิดได้พิมพ์ 🎉"** รอให้ยืนยันอย่างน้อย 5 คน

**ชี้ให้ดูตรงนี้:** ชี้แถบที่อยู่ — "ไม่มีคำว่า localhost แล้ว นี่คือที่อยู่จริงบนอินเทอร์เน็ต ใครก็เปิดได้ และเพราะใครก็เปิดได้ กฎเมื่อกี้ถึงต้องมาก่อนเสมอ" · ย้ำ "**ห้ามใส่ข้อมูลจริงของใครจนกว่ากฎรายห้องจะปิดสัปดาห์หน้า**"

**เชื่อมกับ LeaveEasy:** "บ่ายนี้ส่วน D คุณจะได้ URL ของตัวเอง แล้ว**แลกกับเพื่อนให้เขาลองเปิด** นั่นคือ Checkpoint 4"

> 🆘 deploy ค้างหรือ error → อย่าไล่แก้สดเกิน 2 นาที · เปิด URL สำรองจาก `fixit-week7-end` ที่ deploy ไว้ก่อนคาบ แล้วพูดว่า "ผมเปิดของที่ deploy ไว้เมื่อเช้าให้ดูผลลัพธ์ก่อน"
