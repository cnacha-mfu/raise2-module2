Firebase Authentication — ระบบล็อกอินสำเร็จรูป

  • Authentication = ระบบยืนยันตัวตน (สมัคร/เข้า/ออก)

  • ไม่ต้องเขียนระบบรหัสผ่านเอง — เรื่องนี้พลาดแล้วเจ็บจริง
  • เปิดใช้ใน Firebase Console ก่อน แล้วค่อยสั่ง AI ต่อ
🗒️ ย้ำคำแปล Authentication = ระบบยืนยันตัวตน หรือเรียกสั้น ๆ ว่าล็อกอิน · พูดว่า "การเก็บรหัสผ่านคนอื่นคืองานที่มืออาชีพยังพลาด เราไม่เขียนเองเด็ดขาด ใช้ของสำเร็จที่มีคนดูแลให้"

uid — เลขประจำตัวผู้ใช้

  • สมัครสำเร็จ ระบบออก uid (เลขประจำตัวผู้ใช้) ให้อัตโนมัติ
  • ใช้ uid เป็นชื่อไฟล์ในโฟลเดอร์ users
  • ใบแจ้งใหม่บันทึกช่องผู้แจ้ง = uid ของคนที่ล็อกอินอยู่จริง

🗒️ พูดว่า "uid เหมือนเลขบัตรประชาชนของผู้ใช้ในระบบเรา ระบบออกให้เอง ไม่ซ้ำกันแน่นอน" · ชี้ข้อสาม "ตรงนี้แหละคือคำว่า ระบบรู้จักผู้ใช้ ใบไหนของใคร ตอบได้ทันที" · ข้อสี่บอกว่าค่า role ใช้รหัสอังกฤษตาม spec เพราะสัปดาห์หน้าจะใช้เขียนกฎ

Deploy = นำเว็บขึ้นออนไลน์ให้คนอื่นเปิดได้

  • Deploy = ส่งเว็บจากเครื่องเราขึ้นไปอยู่บนอินเทอร์เน็ต
  • ใช้ Firebase Hosting (บริการที่ทำให้เว็บเรามี URL)
  • localhost = ในเครื่องเราคนเดียว · URL จริง = ใครก็เปิดได้
  • ยังไม่สมบูรณ์ก็ deploy ได้ — ไม่ต้องรอเสร็จร้อยเปอร์เซ็นต์
🗒️ ย้ำคำแปล Deploy = นำเว็บขึ้นออนไลน์ · Hosting = บริการที่ให้เว็บเรามีที่อยู่จริง · พูดว่า "จำคำว่า localhost จากสัปดาห์ที่แล้วได้ไหมครับ วันนี้เราจะเปลี่ยนจาก localhost เป็นที่อยู่ที่ส่งให้ใครก็ได้"
