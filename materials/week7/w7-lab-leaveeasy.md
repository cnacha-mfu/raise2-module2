### A2 — `.gitignore` ก่อน แล้ว push ขึ้น GitHub (15 นาที)

**ทำไมต้องทำก่อน push เสมอ:** ไฟล์ที่เคยขึ้น GitHub แล้ว ต่อให้ลบทีหลัง ก็มีคนคัดลอกไปได้ตั้งแต่วินาทีแรก ลำดับนี้สลับไม่ได้

1. พิมพ์:

   **prompt ที่ใช้ได้ — จังหวะที่ 1:**
   > ตรวจไฟล์ .gitignore ให้กัน node_modules และไฟล์ที่มีคำว่า key หรือ secret
   > แล้วบอกวิธีสร้าง repo บน GitHub และ push ขึ้นไปทีละขั้น
   > ก่อน push ให้แสดงรายชื่อไฟล์ที่จะถูกส่งขึ้นไป ผมจะตรวจเอง

2. 🔍 **คนตรวจอ่านรายชื่อไฟล์ที่จะขึ้นไปให้ทั้งกลุ่มฟัง** พิสูจน์ด้วย:

```
git status
```

   **จะเห็น:** รายชื่อไฟล์ที่จะ commit/push — **ต้องไม่มี** `node_modules` และ**ไม่มี**ไฟล์ที่ชื่อมีคำว่า key หรือ secret
3. สร้าง repo ชื่อโครงงานกลุ่มคุณบน GitHub (Private หรือ Public ก็ได้) → push ตามที่ AI บอกทีละขั้น
4. เปิดหน้า repo บน GitHub → **เลื่อนกวาดตาดูรายชื่อไฟล์ช้า ๆ**

   **prompt ที่ใช้ได้:**
   > ช่วยเขียน Security Rules ของ Firestore ให้ผม 1 ข้อ
   > ต้องล็อกอินก่อน ถึงจะอ่านหรือเขียนข้อมูลได้ ทุกโฟลเดอร์รวมโฟลเดอร์ย่อยด้วย
   > เขียนเสร็จให้ผมอ่านก่อน แล้วบอกวิธี publish กฎ

2. 🔍 **คนตรวจอ่านกฎที่ได้ แล้วชี้ให้ได้ว่าบรรทัดไหนแปลว่า "ต้องล็อกอินก่อน"** (มักเป็นบรรทัดที่มีคำว่า `request.auth`) — ไม่ต้องเข้าใจไวยากรณ์ทุกตัว เข้าใจใจความพอ
3. คัดลอกกฎไปวางในหน้า **Rules** ของ Firebase Console → กด **Publish**
4. ทดสอบ 2 ทาง:
   1. แท็บที่**ล็อกอินอยู่** → รีเฟรช → **ใช้งานได้ปกติ**
   2. หน้าต่างไม่ระบุตัวตน → เปิดหน้ารายการ → **ต้องอ่านอะไรไม่ได้เลย**

   **จะเห็น:** (1) เหมือนเดิมทุกอย่าง (2) หน้าว่างเปล่าหรือขึ้น error — เปิดหน้าต่างข้อความ (F12) เห็น `permission-denied` สีแดง

> 🔧 **ถ้าเป็น LeaveEasy ขั้นนี้จะได้:** หน้าต่างไม่ล็อกอินเปิด `leave-requests.html` แล้วไม่เห็นใบลาสักใบ ขึ้น `permission-denied` — แท็บที่ล็อกอินอยู่ยังใช้งานได้ปกติ — **ของกลุ่มคุณ ทดสอบด้วยหน้าต่างไม่ล็อกอินแล้วเห็นอะไร?**

> ⚠️ **ยังไม่ปลอดภัยจริง** — กฎข้อนี้กันได้เฉพาะคนไม่ล็อกอิน **ใครสมัครบัญชีใหม่ก็ยังเข้ามาอ่านได้หมด** สัปดาห์หน้าจะปิดรายห้อง ระหว่างนี้ห้ามใส่ข้อมูลจริงของใคร

> 🆘 **ใส่กฎแล้ว permission denied ทั้งที่ล็อกอินอยู่:** อาการนี้**ปกติมาก** — หน้าเว็บอ่านข้อมูล**ก่อน**ที่ระบบจะยืนยันเสร็จว่าล็อกอินแล้ว วาง prompt: `ตอนนี้โดน permission denied หลังใส่กฎ ทั้งที่ล็อกอินอยู่ ช่วยตรวจว่าทุกหน้ารอสถานะล็อกอินพร้อมก่อน แล้วค่อยอ่านข้อมูลหรือยัง ถ้ายัง แก้ให้รอก่อนทุกหน้า`

## ส่วน D — 🌐 Deploy ขึ้นออนไลน์ ⏱ ~25 นาที

> ⌨️ คนคุมคีย์บอร์ดรอบ 4 ลงมือ — ระบบที่อยู่ในเครื่องคนเดียวยังไม่นับว่าเป็นระบบ อีก 25 นาทีโครงงานของกลุ่มคุณจะมีที่อยู่จริงบนอินเทอร์เน็ต

### D1 — Deploy เว็บและกฎในรอบเดียวกัน (10 นาที)

**ทำไมต้องพร้อมกัน:** กฎที่เขียนไว้ในเครื่องหรือ publish ไว้ในหน้า Console **ยังไม่คุ้มครองของจริงจนกว่าจะ deploy** — deploy เว็บอย่างเดียวโดยไม่มีกฎเท่ากับเปิดประตูทิ้งไว้ **ห้ามออกออนไลน์โดยไม่มีกฎขั้นต่ำเด็ดขาด**

1. พิมพ์:

   **prompt ที่ใช้ได้:**
   > ช่วยนำเว็บนี้ขึ้น Firebase Hosting บอกผมทีละขั้นว่าต้องพิมพ์อะไร
   > และ deploy Security Rules ขึ้นไปด้วยในรอบเดียวกัน
   > เสร็จแล้วบอก URL ที่ผมส่งให้คนอื่นเปิดได้

2. พิมพ์ตามที่ AI บอกทีละขั้น อ่านออกเสียงทุกคำสั่งก่อนกด → รอ 1–2 นาที

   **จะเห็น:** terminal ขึ้นข้อความ **`Deploy complete!`** และบรรทัด **Hosting URL** ลงท้ายด้วย `.web.app`

> 🆘 **ในเครื่องได้ ออนไลน์พัง:** สาเหตุหลักมี 2 อย่าง — **กฎยังไม่ deploy** (ขึ้น `permission denied`) หรือ **index** (สารบัญช่วยค้น) ยังไม่สร้าง (อ่าน error ให้จบบรรทัด แล้วกดลิงก์สร้าง index ที่แนบมา) — เช็กสองข้อนี้ก่อนเสมอ

### D2 — ยืนยันว่าออนไลน์จริง + แลก URL กับกลุ่มอื่น (15 นาที)

1. เปิด URL ที่ได้ในเบราว์เซอร์ → เห็นหน้าเข้าสู่ระบบ
2. **วาง URL ในแชทกลุ่มตัวเอง** แล้วส่งให้อีกกลุ่มหนึ่งลองเปิด
3. เปิด URL ของกลุ่มอื่นที่เขาส่งมาให้ดู

   **จะเห็น:** เปิด URL ของกลุ่มอื่นแล้วเจอหน้าเข้าสู่ระบบของเขา — สมัครบัญชีใหม่แล้วเข้าใช้งานได้ **แต่ยังไม่เห็นข้อมูลของกลุ่มเขาจนกว่าจะสมัคร/ล็อกอิน** (พิสูจน์ว่ากฎขั้นต่ำทำงานจริง)
4. commit ในชื่อคนคุมรอบ 4 (ถ้ายังไม่ได้ทำ): `git add .` → `git commit -m "deploy ขึ้น Firebase Hosting พร้อมกฎ"`

> 🔧 **ถ้าเป็น LeaveEasy ขั้นนี้จะได้:** URL `leaveeasy-xxxx.web.app` เปิดแล้วเจอหน้าเข้าสู่ระบบขอลา กลุ่มอื่นเปิดแล้วต้องสมัครก่อนถึงจะเข้าได้ — **URL ของกลุ่มคุณคืออะไร ใครเปิดให้ดูสำเร็จบ้าง?**

> ⚠️ **ออนไลน์แล้วก็ยังห้ามใส่ข้อมูลจริง** — ใครสมัครบัญชีใหม่ก็ยังอ่านได้หมด กฎรายห้องปิดสัปดาห์หน้า ก่อนนั้นใช้ชื่อสมมติเท่านั้น

→ 🚩 **Checkpoint 3: ล็อกอินได้ + ไม่ล็อกอินอ่านไม่ได้ + กลุ่มอื่นเปิด URL ของกลุ่มคุณได้**
📸 คนจดโพสต์ 3 ภาพลงแชท: ① หน้าต่างไม่ล็อกอินที่อ่านไม่ได้ ② Console ที่เห็น uid ในรายการ ③ URL ที่กลุ่มอื่นยืนยันว่าเปิดได้ — พร้อมชื่อกลุ่มและไฟจราจร
